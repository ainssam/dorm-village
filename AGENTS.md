# Repository entry point

The editable web game is in `game/`. Read `game/README.md` and `game/AGENTS.md` before making changes, and run its commands from that directory.

`references/npc-originals/` holds the original NPC concept images and inventory. Preserve those originals unless the user specifically requests changing them.

Keep changes scoped to the requested feature. Do not assume a GitHub commit deploys the public game. Publishing the live site is a separate action.
