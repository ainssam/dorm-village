`game/`은 2026년 10월 11일 공개된 v149를 기준으로 정리한 소스입니다. 게임의 JavaScript, 화면, 모델, 소리, 글꼴 및 필요한 라이선스 고지를 포함합니다. 실행과 검사는 `game/` 안에서 진행합니다.

Codex 등의 코딩 도구에서 이 저장소를 열고 `game/README.md`와 `game/AGENTS.md`부터 읽도록 요청하면 됩니다. 수정한 코드는 작업 브랜치에서 검토한 뒤 반영합니다. GitHub의 변경 내용이 위 공개 사이트로 자동 배포되는 연결은 설정하지 않았습니다. 공개 사이트 업데이트는 별도로 검증하고 게시해야 합니다.

## 이용 조건

저장소 전체에 적용되는 새 라이선스는 지정하지 않았습니다. 공개 열람만으로 모든 코드·그림·모델에 무제한 재사용 권한이 부여되는 것은 아닙니다. 재사용할 때는 각 자료의 출처와 이용 조건을 확인하세요. 게임에 포함된 외부 라이브러리·글꼴·데이터의 라이선스 고지를 함께 보존해야 합니다. AI 생성 자료의 저작권이나 독점성을 일괄 보장하지 않습니다.
