## 게임 소스

이 첫 공개 커밋에는 NPC 원본과 목록이 들어 있습니다. 실행 가능한 게임 소스는 별도 확인 후 같은 저장소에 추가할 예정이며, 현재 이 커밋에 게임 실행 파일이 들어 있다고 주장하지 않습니다.

## 이용 조건

저장소 전체에 적용되는 새 라이선스는 지정하지 않았습니다. 공개 열람만으로 모든 그림에 무제한 재사용 권한이 부여되는 것은 아닙니다. 재사용할 때는 캐릭터별 출처와 해당 자료의 권리를 별도로 확인하세요. AI 생성 자료의 저작권이나 독점성을 일괄 보장하지 않습니다.
