# 도름이 마을 게임 코드

이 폴더에 브라우저에서 바로 실행할 수 있는 도름이 게임과 필요한 그림·소리·모델이 들어 있어요. 코드는 `game/` 안에 두었으니 기존 저장소의 NPC 안내 문서와 다른 파일은 그대로 둘 수 있습니다.

## 내 컴퓨터에서 실행하기

1. Node.js와 npm을 설치해 주세요.
2. 터미널에서 이 폴더(`game/`)로 이동해 `npm ci`를 실행해 주세요.
3. `npm run serve`를 실행하고 브라우저에서 http://127.0.0.1:4173 을 열어 주세요.
4. 멈추려면 터미널에서 Ctrl+C를 누르면 됩니다.

인터넷에 게시하지 않고 내 컴퓨터에서만 열리는 간단한 정적 서버예요. 로그인이나 별도 계정 정보는 필요하지 않습니다.

## 코드를 바꾸거나 확인하기

`dist/`의 JavaScript 모듈이 게임의 실제 편집 가능한 코드예요. 빌드 결과만 담긴 폴더가 아닙니다. 파일을 바꾼 뒤 `npm run check`로 JavaScript 문법을 확인하고, `npm test`로 포함된 핵심 회귀 테스트를 실행할 수 있습니다. `npm run test:focused`는 같은 테스트를 이름을 분명히 적어 실행하는 명령입니다.

이 패키지에는 최근 카메라·이동·마을·공항·비행 회귀를 확인하는 40개 테스트 파일만 포함돼 있어요. 패키징 시점에 `npm run check`가 통과했고, `node --test --test-concurrency=1 tests/*.test.mjs`에서 189개 테스트가 모두 통과했습니다. 기존 157개 검사에 시작·복귀 관련 검사 32개를 더한 결과입니다. 예전 전체 프로젝트 테스트 묶음이나 오래된 QA 캡처 자료는 포함하지 않았습니다. 원본의 넓은 테스트 묶음에서는 오래된 캡처 `qa/noticeboard-public/public-dom-capture.json`이 없어 생기는 기존 실패가 보고돼 있습니다. 따라서 여기서의 `npm test` 결과를 원본 전체 테스트 결과로 해석하지 말아 주세요. 이 패키지는 그 전체 범위를 통과했다고 주장하지 않습니다. 이 테스트는 브라우저에서 직접 플레이하는 확인이나 모바일/WebGL 성능 검증을 대신하지 않습니다.

`source/`에는 안전한 공개 입력만 골라 담은 일부 Blender/Python/Node 에셋 생성 코드도 있습니다. 이 도구들은 Blender나 하위 폴더별 제작 의존성이 필요할 수 있어 `npm ci`만으로 모두 실행되지는 않습니다. `npm run build:math`는 MathLive/MathJax 표시 모듈을 다시 만들 때 사용하는 선택 명령입니다. 일반 실행에는 필요하지 않습니다. 게임을 빌드해 자동 게시하거나 외부 서비스에 배포하는 명령은 들어 있지 않습니다.

## 저작권 안내

타사 모델·폰트·음악·라이브러리 고지문은 `dist/licenses/`와 각 `dist/vendor/` 폴더에 있어요. 에셋을 바꿀 때 관련 고지문도 함께 보존해 주세요. 게임에는 여러 라이선스가 함께 있으므로 새 통합 라이선스를 임의로 추가하지 않았습니다.

페이지를 떠났다가 브라우저의 뒤로 가기로 돌아온 뒤에도 간식 카트를 다시 열 수 있도록, 종료된 주문 호스트를 재사용하지 않게 수정했습니다. 실제 입력·근접 선택·페이지 복귀를 연결한 회귀 검사로 확인했으며, 이 검사는 실제 휴대폰 화면 검수를 대신하지 않습니다.

물고기 게임·인형뽑기·간식 카트의 생성 함수를 ES 모듈 최상위 범위로 옮겨, 부팅과 상호작용에서 함수 이름을 찾지 못하던 오류를 수정했습니다. 실제 브라우저에서 기존 시작 오류가 사라짐을 확인했으나, 확인 환경의 WebGL 제한으로 3D 장면의 조작 검수까지 완료한 것은 아닙니다.

터치 기기의 인형뽑기에는 마을 이동과 같은 모양의 아날로그 스틱을 제공합니다. 손가락을 떼면 이동을 멈추고, 취소·화면 전환에는 입력을 정리합니다. 데스크톱 방향 버튼과 키보드 조작은 유지됩니다. 좁은 가로 화면에서는 조작 패널을 스크롤할 수 있습니다. 입력·크기 규칙 검사는 통과했으며 실제 휴대폰의 3D 조작감 검수는 별도로 필요합니다.

시작 파일 로딩·실행 실패 안내와 중복 실행 없는 재시도, 뒤로 가기 후 배경음·날씨 등 자원 복구 정책을 보완했습니다. [재현 방법·수정 내용·검증 결과](docs/startup-return-stability.md)를 확인해 주세요. 실제 3D 브라우저 동선 검수는 WebGL 지원 환경에서 추가 확인이 필요합니다.


## Dorm Village 출시 구성

- Vercel 프로젝트 루트는 `game`, 정적 출력은 `dist`, 검증 명령은 `npm run check && npm test`입니다. `vercel.json`에 배포 헤더를 포함합니다.
- 새 도름이는 `ainssam/doreumi-desktop-pet`의 Meshy 마스터 모델을 원래 관절·스킨·표정으로 렌더링합니다. 기존 활동 좌표를 CPU 참조 모델에서 새 관절로 연결하여 저장과 활동 계약을 유지합니다.
- 출처와 원본/파생 파일 해시는 `dist/characters/doreumi/source.json`, 라이선스는 `dist/licenses/`에 있습니다. 자산 재생성: `node scripts/prepare-doreumi.mjs <원본-master.glb-경로>`.
- 브라우저 검수: 로컬 서버 실행 후 `QA_OUT=qa/review QA_INTERACTIONS=1 node scripts/audit-browser.mjs`. Chromium 경로는 `CHROMIUM_PATH`로 지정합니다. `QA_SCENARIO=1`, `QA_RECOVERY=1`, `QA_MOBILE=1`로 사용 흐름·저장/오류·모바일 검사를 실행합니다. 테스트용 이동 브리지는 Playwright 요청 가로채기에서만 주입됩니다.
- 기록은 현재 사이트 주소의 브라우저에 저장됩니다. 새 배포 주소로 기존 사이트 기록이 자동 이전되지 않습니다.
- 검수 결과와 실제 검증 한계: `qa/RELEASE-REPORT.md`.

## 2026-10-25 보행·사용성 재검수

새 도름이의 보행을 실제 관절로 구성하고, 움직이는 좌석에서 피부 메시가 가라앉던 변환 순서와 캐시된 손 좌표를 수정했습니다. UI는 Pretendard로 정리했고, 놀이 검색·완료 후 재시작·휴대폰 로봇 실행 도구를 개선했습니다. 4개의 실제 모델 회귀 검사가 추가되어 현재 핵심 검사는 193개입니다.

`QA_POLISH=1 node scripts/audit-browser.mjs`로 완료·재시작·이어하기 흐름을, `QA_POSES=1`로 착석 완료 및 퇴장을 검사합니다. 휴대폰은 `QA_MOBILE=1`, 움직임 줄이기는 `QA_REDUCED=1`입니다. 기본 검사는 일반 동작 설정을 사용합니다. 렌더러가 느린 환경에서 `QA_RENDER_SCALE=.5`로 캡처 해상도를 낮출 수 있으며 실제 휴대폰 GPU 성능 검사와 구분해야 합니다. 상세 결과는 `qa/RELEASE-REPORT.md`에 기록합니다.
