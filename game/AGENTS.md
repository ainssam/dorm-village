# 게임 폴더 작업 안내

- 이 하위 폴더만 독립적인 게임 패키지입니다. 저장소 최상단의 기존 NPC 안내 문서와 그 링크는 수정·이동·삭제하지 마세요.
- `dist/`는 게임의 실제 편집 가능한 ES 모듈 코드와 런타임 자산입니다. 생성물만 담은 디렉터리로 취급하지 말고, 상대 경로 import 및 에셋 참조를 유지하세요.
- Node.js/npm 설치 후 `npm ci`, `npm run check`, `npm test`로 확인합니다. `npm test`는 이 패키지에 포함된 39개 핵심 테스트 파일만 실행하며 원본 전체 회귀 테스트를 뜻하지 않습니다.
- 로컬 미리보기에는 `npm run serve`를 사용합니다. 서버는 `127.0.0.1:4173`에만 열리고 `dist/` 파일만 제공합니다. 자동 사이트 게시·배포는 하지 않습니다.
- 일반 실행에는 계정이나 자격 증명이 필요하지 않습니다. 토큰·비밀키·로컬 작업 경로·개인 메모·Library 식별자를 파일에 추가하지 마세요.
- `dist/licenses/`와 `dist/vendor/` 안의 타사 라이선스·저작권 고지를 삭제하거나 덮어쓰지 마세요. 서로 다른 라이선스를 하나의 프로젝트 라이선스로 합치지 마세요.
- `source/`에는 선택된 모델·이미지·지도·음악 에셋 생성 코드와 비공개 작업 흔적을 제거한 안전한 입력만 포함됩니다. 일부 도구는 별도 Blender/Python 의존성이 필요합니다. MathJax 생성 입력은 `source/math-renderer.mjs`입니다. 런타임 코드는 `dist/`에서 직접 편집합니다.
