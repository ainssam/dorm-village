# 도름마을 전체 경험 점검 및 도름스 출시 Implementation Plan

> **For agentic workers:** Use `superpowers:subagent-driven-development` review principles to implement and verify the independently owned tasks. Checkboxes track actual completion.

**Goal:** 유용하고 편안한 마을 경험을 휴대폰·태블릿·컴퓨터에서 검증하고 개선판을 공개 배포한다.
**Architecture:** 기존 정적 ES 모듈과 3D 활동 컨트롤러를 유지한다. 놀이 모형과 화면/입력을 분리하고 공유 게임 소유권·저장 구조에 맞춘다.

## Global Constraints
- `game/dist`는 직접 편집하는 소스다. 기존 저장·상대 경로·자산 출처·라이선스를 보존한다.
- 직접 확인한 결과와 문서/소스 기반 판단을 분리한다. 현재 작업에서 새로 캡처한 증거를 사용한다.
- 휴대폰·태블릿·컴퓨터의 주요 흐름을 모두 확인한다. 소프트웨어 WebGL 검증을 실물 기기 성능 측정으로 표현하지 않는다.
- 사용자에게 이미 허가받은 GitHub 현행화·Vercel 배포는 다시 허가를 묻지 않는다. 실제 도름스 로그인 부재만 별도 완료 상태로 기록한다.
