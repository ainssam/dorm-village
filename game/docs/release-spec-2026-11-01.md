# 도름마을 공개 출시 기준 · 2026-11-01

## 사용자의 목표
휴대폰·태블릿·컴퓨터에서 쉽게 즐기며 쉬어 갈 수 있고, 교실과 생활 공간의 활동이 실제로 쓸모 있는 앱으로 개선한다. 모든 장소와 기능을 점검하고 놀이공원은 상용 제품의 설계 원칙과 비교한다. 기능 검증과 내용/사용성 판단을 구분한다. GitHub를 현행화하고 아인2 Vercel `dorm-village`에 개선판을 공개 배포하며 도름스(`https://dorms.school`)에 소개할 수 있도록 준비한다.

## 제품 원칙
- 1분 안에 무엇을 해볼지 고를 수 있고, 설명 → 직접 행동 → 알아볼 수 있는 결과 → 재도전/나가기 흐름이 분명해야 한다.
- 힐링은 강제 출석·연속 기록·실패 벌점 없이 자기 속도로 선택하고 중단할 수 있는 경험이다. 쉬는 놀이기구를 억지 점수 게임으로 바꾸지 않는다.
- 교육 활동은 관찰/설명과 실제 모형이 일치해야 한다. 짧은 탐색 활동을 정규 교육과정이나 검증된 학습 효과로 과장하지 않는다.
- 터치·마우스·키보드에서 주요 기능을 완료할 수 있어야 한다. 휴대폰 세로/가로, 태블릿 세로/가로, 데스크톱에서 조작·닫기·재시도가 가려지지 않아야 한다.
- 기존 저장·관절 동작·사진·탑승 기능, 원본 자산·라이선스 고지와 상대 경로를 보존한다. 새로운 계정·결제·개인정보 수집은 추가하지 않는다.
- 사용자 추가 지시: 크림·민트·살구·연분홍·라벤더의 파스텔 미감을 선호한다. 아기자기한 색과 필요한 아이콘/이미지를 보완하며 글자 대비를 유지한다. 실제 도름이를 기반으로 파비콘과 카카오톡 홍보 이미지, 링크 공유용 대표 이미지를 만든다.
- 사용자 선택: 마을 안 게시판의 도름스 앱 목록은 ‘오늘의 작은 발견’으로 교체한다. 검토한 읽을거리·마을 놀이·마음 질문으로 구성한 60개 카드를 한국 날짜에 맞춰 순환하고 지난 7일을 다시 볼 수 있게 한다. 실시간 새 기사 수집으로 오인시키거나 출석 보상을 추가하지 않는다.

## 출시 합격 기준
1. 현재 코드 기준 공간/활동 전수 목록을 만들고 모든 진입·퇴장에 오류가 없음을 새 브라우저 실행으로 확인한다.
2. 모든 고유 활동 유형에 대해 목표·조작·결과·반복 가치·내용 적절성을 검토한다. 진입 검사와 끝까지 완료한 시나리오를 별도로 기록한다.
3. 발견한 P0(진입 불가/저장 손실/잠김)와 P1(핵심 놀이 무의미/내용 오류/주요 기기 조작 불가)을 수정하고 재현 근거와 수정 검증을 남긴다.
4. 뜰채의 조준 의미, 카트의 쉬운 재도전, 범퍼카의 명확한 행동/피드백을 개선한다. 언어 교실의 탭 진도 소실과 요리 설명 불일치를 바로잡는다.
5. 상용 앱 4종 이상의 공식 자료를 근거로 비교한다. 직접 해보지 않은 제품은 직접 플레이 검증처럼 표현하지 않는다.
6. `npm run check`, `npm test`, 새 활동 회귀, 기기별 실제 브라우저 흐름, 저장/복구/실패 경로가 통과한다.
7. 최종 독립 리뷰 후 GitHub와 공개 배포의 커밋·버전을 대조한다. 실물 모바일 GPU/iOS Safari 미검증 범위를 숨기지 않는다.
8. 도름스 등록은 Vercel 배포와 구분한다. 현재 연결 도구에 교사 인증 세션이 없어 게시 확인 전에는 등록 완료라고 쓰지 않는다. 공개 URL·소개·화면·사용 안내를 준비한다.
