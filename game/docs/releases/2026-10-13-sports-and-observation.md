# 운동 공간 정리와 천체 관측 보기 개선

## 재현과 원인

운동장의 축구 코트(가로 11.4, 세로 5.6) 내부에 철봉과 정글짐의 물리적 배치가 겹쳤습니다. 천문대 수성은 관측 표면 지도 없이 균일한 회색 구체였고, 다른 설명용 행성도 형태를 구별할 세부 표현이 부족했습니다. 토성 고리는 최초 시점에서 거의 옆면만 보여 고리의 띠를 관찰하기 어려웠습니다.

## 반영 내용

- 축구 코트와 골대·공은 유지하고 철봉·정글짐을 남쪽 별도 운동 구역으로 옮깁니다. 출입 통로와 트랙을 보존하며, 시각적 위치·충돌 판정·체험 시작 위치·손발 접촉을 함께 맞춥니다.
- 복싱 구역 바닥 경계와 모서리 패드, 복싱·양궁 안내, 레이저 사격 표적 옆의 시각적 구성을 보강합니다. 기존 운동의 점수·동작 판정은 보존합니다.
- 수성은 NASA PIA12397의 축소 모자이크를 사용합니다. 원자료의 해상도와 현재 제공용 이미지의 해상도를 구별하고 관측 누락 부분을 설명합니다.
- 달·수성·화성·목성의 검증된 표면·대기 이미지는 별도 색을 덧씌우지 않습니다. 조명 균형을 조절해 구체의 명암을 더 잘 구분하도록 합니다.
- 금성·토성·천왕성·해왕성에는 가벼운 설명용 색조 무늬를 적용합니다. 실제 관측 지도나 현재 날씨라고 표시하지 않습니다.
- 토성은 여러 고리 띠와 설명용 카시니 간극을 나누고 처음부터 고리 면이 보이는 시점으로 조절합니다. 고리 비율은 설명용입니다.

## 보존 및 한계

활동·발견 ID와 저장 키, NPC 원본과 기존 라이선스를 보존합니다. 새 수성 이미지의 출처·크레딧·바이트와 검증 해시는 solar-system/SOURCES.md에 기록합니다. 실제 지형 고도와 실시간 망원경 관측을 구현한 변경은 아닙니다.

현재 실행 환경에서 실제 WebGL 브라우저 플레이 검수는 완료하지 못했습니다. 기하 투영·모형 접촉·호스트 검사 결과를 실제 휴대폰 화면 검수나 FPS 측정으로 표현하지 않습니다. 브라우저 회귀 검사 코드는 추가했지만 실행 성공으로 간주하지 않습니다.

## 검증 결과

- 전체 authored JavaScript 문법 검사 통과. 최종 변경된 JavaScript 파일을 다시 검사해 통과했습니다.
- 기존 핵심 및 접근 거리·천체 관측 회귀 검사: 43개 파일, 223/223 통과.
- 체육시설 집중 검사: 배치·호스트·경로·저장/발견 28/28, 실제 GLB 접촉 2/2, 복싱·사격·양궁 접촉 19/19 통과. 달리기 트랙의 720개 위치와 출입 통로를 검사했습니다.
- 천체 관측 집중 검사 20/20 통과. 생성 색조의 바이트 넘침 방지, 폐기되는 자원, 토성 고리의 실제 Three.js 투영을 검사했습니다. 390×500 및 1280×800에서 고리의 화면 여백을 확인했습니다.
- 집중 검사 일부는 핵심 검사와 중복됩니다. 위 수치를 모두 더해 고유 검사 총수로 표현하지 않습니다.
- 확장된 전체 테스트를 한 차례 시작했으나 기존 비관련 오류와 동시 수정으로 인한 결과가 섞여 중단했습니다. 전체 npm test 통과를 주장하지 않습니다.
