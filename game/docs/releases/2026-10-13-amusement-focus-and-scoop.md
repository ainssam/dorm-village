# 놀이공원 체험 집중 화면과 뜰채 동작

## 변경
- 음식 주문을 시작하면 선택한 카트와 도름이에 자동으로 초점을 맞추고, 주문창과 화면 조작부를 피해 배치합니다. 종료 시 이전 카메라·확대 상태로 돌아갑니다.
- 작은 가로 화면의 주문창을 간결하게 배치하고, 주문 중 불필요한 지도 도구를 숨겼다가 복원합니다.
- 음식 소품 준비 실패 시 안내가 닫힌 창에 가려지지 않도록 복구 가능한 오류를 표시합니다.
- 뜰채를 천천히 물속에 넣고, 물속에서 움직인 뒤 들어 올리도록 단계와 시간을 변경했습니다. 내려찍는 시점이 아닌 물속 이동 종료 시 기존 거리 기준으로 잡힘을 판단합니다. 잡힌 물고기는 뜰채와 함께 올라갑니다.

## 재현 및 확인
1. 음식 카트에 접근해 주문을 시작하고 취소·완료·화면 회전·재시작을 확인합니다.
2. 뜰채 게임에서 물속 이동과 들어 올리는 단계, 잡힌 물고기, 일시정지·닫기·재시도를 확인합니다.
3. 인형뽑기와 범퍼카는 기존 자동 맞춤 화면과 조작·종료 연결을 코드 및 관련 검사로 점검했습니다.

## 검증 범위
- 선택된 회귀 검사 251개 통과, 전체 JavaScript 문법 검사 통과.
- 카메라 투영·작은 가로 화면·기존 시점 복원과 뜰채 단계·자원 정리 검사를 포함합니다.
- 실제 PC·휴대폰 WebGL 화면과 체감 조작은 이번 환경에서 검증하지 못했습니다. 전체 테스트 묶음 통과를 의미하지 않습니다.
- 저장 형식과 NPC 원본·라이선스는 변경하지 않았습니다.

- 별도 범퍼카 광범위 검사에서는 52개 중 50개가 통과하고, 2개는 VM 테스트 환경의 amusementFoodHost 누락으로 실패했습니다. 해당 실패를 실제 실행 오류로 확인한 것은 아니며 미해결 검사 한계로 남깁니다.
