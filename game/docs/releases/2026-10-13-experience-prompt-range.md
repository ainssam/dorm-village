# 체험 버튼 접근 거리 완화

## 변경 내용

체험 안내가 너무 가까이 가야 나타나는 문제를 줄이기 위해, 짧게 설정된 체험의 버튼 인식 거리를 공통 기준으로 넓혔습니다. 기존 반경이 1.1 미만인 대상만 원래 값에 0.4를 더하되 최소 1.05, 최대 1.35로 제한합니다. 이 수치는 게임 좌표 기준입니다. 이미 1.1 이상인 대상은 유지합니다.

- 놀이터 그네·미끄럼틀 등 짧은 체험: 0.4 → 1.05
- 망원경: 0.42 → 1.05
- 인형뽑기: 0.65 → 1.05
- 회전목마·바이킹·먹거리 등: 0.7 → 1.1
- 체육관 도구·일부 교실 체험: 0.85 → 1.25
- 집 안 레시피·로봇·균형 건축 체험: 0.95 → 1.35

원본의 위치·물리적 크기·저장 데이터는 바꾸지 않습니다. 버튼을 보여 주는 거리와 실제 실행 시 확인하는 거리가 달라지는 일을 막기 위해, 선택 결과에는 확장된 반경을 전달합니다. 동일한 선택 결과를 다시 사용하거나 복사해도 반경이 반복해서 늘어나지 않도록 했습니다.

## 유지하는 안전 조건

- 벽과 장애물 사이의 접근 경로를 계속 검사합니다.
- 여러 체험이 겹치면 기존 우선순위와 가까운 대상 선택 규칙을 유지합니다.
- 버튼을 직접 눌러야 시작합니다. 가까이 가는 것만으로 자동 실행하지 않습니다.
- 문·배·비행기·엘리베이터·주민 대화·의자와 침대의 휴식 동작은 이번 확대에서 제외했습니다.
- 이미 넓게 설정된 대상, 0 이하 또는 유효하지 않은 반경은 임의로 활성화하지 않습니다.

## 재현 및 확인 방법

1. 놀이터 그네나 천문대 망원경 앞에서 조금씩 접근합니다. 기존보다 떨어진 지점에서 체험 버튼을 확인합니다.
2. 버튼이 보이는 위치에서 눌러 실제 체험이 열리는지 확인합니다. 망원경은 확대된 반경을 실행 검사에도 전달하는 회귀 검사를 추가했습니다.
3. 장애물 뒤쪽과 확장 범위 밖에서는 버튼이 나타나지 않는지 확인합니다.
4. 가까이 붙어 있는 체험 사이를 이동하며 선택 대상이 바뀌는지 확인합니다. 문과 승하차 동작의 기존 조건도 유지합니다.

실제 PC·휴대폰 브라우저 화면 및 조작 체감 검수는 별도로 필요합니다. 테스트에서 계산한 접근 가능 여부를 실제 기기 화면 검수로 표현하지 않습니다.

## 자동 검사 결과

- 문법 검사와 변경 파일의 최종 문법 검사 통과, 공백 오류 검사 통과.
- 접근 거리·망원경 실행·놀이기구 접근 집중 검사 33/33 통과. 추가 놀이터·인형뽑기 포함 독립 검토 53/53 통과(서로 중복되는 검사이며 합산하지 않음).
- 기존 핵심 검사와 주변 기능을 합친 56개 파일: 291개 중 287개 통과, 4개 실패. 실패는 체육관 호스트의 `fishScoop` 미정의, 비행·배 도착 검사 및 이를 포함한 상위 검사입니다. 전부 통과했다고 판단하지 않습니다.
- 별도 기존 코드 비교에서 비행·배 도착 실패가 수정 전 02c2f863에서도 재현됐습니다. 추가 탐색에서 발견한 배 동선과 공항 포털 검사 오류도 같은 기준 코드에서 재현됐습니다. 체육관 호스트 미정의 오류는 이전 검증에서 이미 확인된 항목입니다. 이번 변경은 이 오류를 해결하지 않습니다.
- 원본 NPC·이미지·라이선스, 저장 데이터와 저장 키 변경 없음.
