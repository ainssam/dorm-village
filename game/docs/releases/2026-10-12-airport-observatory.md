# 공항 전망 데크·여행자 카페·천체 3D 탐험

## 이용 방법과 수정 내용

1. 본섬 공항의 북서쪽 해안으로 이동합니다. 새 전망 데크 벤치에서 앉기를 선택하고 ‘비행기 바라보기’를 누릅니다. 기존 비행장과 비행기를 바라보며, 닫으면 앉아 있던 자세와 이전 카메라로 돌아옵니다. 기존 공항 벤치는 그대로입니다.
2. 데크 서쪽 ‘공항 카페’ 앞에서 음료를 주문합니다. 아메리카노·카페라테는 무료이며 사과주스는 기존 재료인 사과 2개가 필요합니다. 준비가 끝나면 직접 수령합니다. 음료는 기존 음식 주머니에 저장됩니다. 패널의 닫기 또는 Escape로 돌아가면 걸어 다닐 수 있습니다. 들고 다니는 시각물은 개별 컵이 아니라 기존 주머니입니다.
3. 천문대 망원경에서 달이나 행성을 선택하고 ‘3D로 탐험’을 누릅니다. 드래그·확대·방향 버튼으로 관찰하고, ‘하늘 관측으로 돌아가기’로 같은 관측 대상·시각·장소를 유지한 채 돌아옵니다. 닫기 버튼은 3D 화면과 로딩 오류 상태에서도 사용할 수 있습니다.

## 자료와 표현의 범위

- 달·화성·목성에는 출처와 해시를 확인한 관측 기반 지도를 사용합니다. 현재 순간의 실제 자세·조명이나 표면 지형의 높이를 재현하는 화면은 아닙니다.
- 수성·금성·토성·천왕성·해왕성은 설명용 모형입니다. 토성 고리는 단순화한 기하이며 크기 비율도 실제와 같다고 보장하지 않습니다.
- 목성 지도의 극지방 검은 띠는 자료가 없는 영역입니다. 실제 목성의 색이 아닙니다.
- 달 높이 자료의 결측값 규칙을 확인하지 못해 지형 굴곡에는 적용하지 않았습니다. 고용량 달·토성 3D 파일은 자동으로 내려받지 않습니다.
- 전체 출처·크레딧·이용 조건은 `../../dist/world/solar-system/SOURCES.md`에 정리했습니다. 앱 안에서도 출처와 한계를 확인할 수 있습니다.

## 검증

- 현재 공개 저장소의 핵심 검사와 카메라·데크·장면 연결 검사: 210/210 통과.
- 천체 자료·렌더러 수명·관측 모달·기존 2D 하늘 검사: 31/31 통과.
- 여행자 카페·기존 카페 UI·호스트 관련 최종 검사: 32/32 통과. 세 묶음에는 중복 검사가 있으므로 합계를 독립 검사 수로 세지 않습니다.
- 전체 작성 JavaScript 문법 검사 및 최종 변경 파일 문법 검사 통과. 기존 이미지·모델·오디오·폰트·라이선스 파일 230개는 이전 버전과 바이트 단위로 같았습니다.
- 데크 추가분은 312개 삼각형, 정적 배치 1개, 새 텍스처 0개입니다. 실제 좌석 접근·이탈 및 카메라/비행기 표시 고정의 획득·해제를 검사했습니다.
- 천체 화면은 잦은 열기·닫기, 취소된 이미지 디코딩, 재시도 시 이전 이미지 해제, WebGL 복구 전 재시도, 직접 닫기와 늦게 도착한 모듈을 검사했습니다.
- 저장 형식과 기존 음식 저장 액션을 유지했습니다. 실제 사용자의 브라우저 저장 기록을 직접 열어 확인한 것은 아닙니다.

## 확인 범위와 남은 점

실제 PC·휴대폰 브라우저 화면 및 기기 GPU/FPS 검사는 수행하지 않았습니다. 브라우저용 시나리오 파일은 문법 및 목록을 확인했으며, 실제 실행 검수가 필요합니다. 데크까지의 충돌 없는 길은 확보했지만 마지막 구간은 포장길이 아니라 풀밭입니다.

추가로 실행한 오래된 보존/실제 프레임 검사 일부는 이번 변경 전 기준 커밋 `ac7e2c6`에서도 같은 실패가 재현됐습니다. 누락된 테스트용 변수, 이전 출입구 기대값 및 파일 전체 목록 보존 조건에 관한 것으로, 이번 변경의 검사 통과와 구분했습니다. 전체 테스트가 모두 통과했다고 주장하지 않습니다.
