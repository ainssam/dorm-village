# 시작·화면 복귀 안정화

2026년 10월 12일 검토. 기존 v156을 기준으로 수정했습니다.

## 수정 전 재현 방법

1. 게임에서 소리를 켜고, 원하는 경우 날씨도 직접 켭니다.
2. 다른 웹페이지로 이동했다가 브라우저의 뒤로 가기로 돌아옵니다.
3. 브라우저가 이전 문서를 보관했다가 복구한 경우(`pagehide.persisted`, `pageshow.persisted`), 기존 코드는 배경음과 날씨를 완전히 종료했지만 일부 도구만 재생성했습니다. 화면은 남아 있어도 종료된 기능은 다시 작동하지 않을 수 있었습니다.
4. 시작 파일인 `game.js`나 그 의존 파일을 불러오지 못하면, 기존 재시도 버튼을 연결하는 코드도 실행되지 않아 로딩 상태에서 벗어나지 못했습니다.

## 수정 내용

### 복귀 정책

| 대상 | 뒤로 가기 복귀가 예정된 경우 | 문서를 완전히 떠나는 경우 |
|---|---|---|
| 배경음 | 재생을 멈추고 오디오 전환을 순서대로 처리합니다. 기존 설정·오디오 자원을 유지하며, 이전에 사용자가 허용한 소리만 재개를 시도합니다. 브라우저가 거부하면 다시 누르도록 안내합니다. | 재생과 오디오 자원을 종료합니다. |
| 날씨 | 진행 중 요청과 표시 효과를 멈추되, 사용자가 선택한 도시·켜기 여부·표시 설정·캐시와 요청 간격을 유지합니다. 꺼져 있던 날씨를 자동으로 켜지 않습니다. | 요청·표시 효과·리스너를 종료합니다. |
| 캠핑·광장·엘리베이터 | 진행 중 활동을 취소하고 다시 사용할 수 있는 제어기를 유지합니다. | 제어기를 종료합니다. |
| 배·비행·전망·물고기·베이커리 | 이전 활동을 종료하고 필요한 제어기를 다시 만듭니다. 간식 주문은 다음 사용 때 새로 만듭니다. | 종료합니다. |
| 저장 | 기존처럼 저장 잠금을 해제하고 복귀 화면은 읽기 전용으로 둡니다. 새로고침 전에는 진행을 저장하지 않습니다. | 저장 잠금을 해제합니다. |
| 안내창 | 이전 창의 닫힘 처리가 지연되어 새 창을 열 수 없으면 짧은 상태 안내로 새로고침 필요성을 알립니다. | 기존 닫기 처리를 유지합니다. |
| 문서 연동 도구 | 같은 문서의 등록을 보존하고 중복 등록하지 않습니다. | 등록을 해제합니다. |

문서 연동 도구의 실제 BFCache 등록 유지 여부는 브라우저·호스트별 실증 확인이 남아 있습니다.

### 시작 오류와 재시도

- 시작 파일 로딩 또는 실행 실패를 잡아 오류 안내와 ‘다시 열기’를 표시합니다.
- 재시도는 게임을 중복 초기화하지 않고 페이지 전체를 한 번 새로고침합니다.
- 빠르게 두 번 눌러도 재시도는 한 번만 요청합니다.
- 정상 시작에서는 기존 3D 오류 안내·재시도 동작을 유지합니다.
- 재시도 코드가 저장 데이터를 삭제하거나 초기화하지 않습니다.

## 검사 범위

JavaScript 문법 검사를 통과했습니다. 공개 패키지 39개 테스트 파일에서 기존 157개와 추가 32개를 합친 189개 검사가 모두 통과했습니다(실패·건너뜀 0개). 새 검사에는 반복 복귀, 늦게 끝나는 오디오 정지·재생, 브라우저의 소리 재개 거부, 늦게 도착하는 음원·날씨 결과, 날씨 꺼짐·캐시 유지, 안내창 닫힘 지연, 모듈 실패·부분 실행 뒤 재시도·중복 클릭이 포함됩니다.

모의 환경에서 실제 모듈을 사용한 검사는 실제 브라우저에서 플레이한 결과와 다릅니다. 예전 전체 개발용 검사에는 기존 fixture 참조 실패가 남아 있어 전체 통과라고 주장하지 않습니다.

## 실제 브라우저 확인과 남은 제한

- 공개 페이지 진입, 기존 3D 실패 안내, ‘다시 열기’, 일반 HTTPS 페이지로 이동한 뒤 브라우저 뒤로 가기로 앱 URL에 돌아오는 동작을 확인했습니다.
- 확인 환경은 WebGL을 사용할 수 없어 3D 실패 안내가 지속됐습니다. 따라서 실제 3D 시작·장소 이동·활동 종료·저장·재접속과 게임 상태의 BFCache 복구는 검증을 완료하지 못했습니다.
- 모듈 네트워크 실패는 회귀 검사로 확인했으며, 실제 브라우저 요청 차단으로 재현한 결과는 아닙니다.
- NPC 원본을 포함한 이미지·모델·음원·vendor·라이선스 파일 209개의 기존 바이트가 유지됐습니다.

### 3D 지원 브라우저에서 남은 수용 검사

1. 시작 후 장소를 바꾸고 활동을 시작·종료합니다.
2. 진행을 저장하고 페이지를 다시 열어 저장 결과를 확인합니다.
3. 소리와 날씨를 각각 켠 경우·끈 경우를 나누어 다른 HTTPS 페이지에 다녀옵니다.
4. 실제 `pageshow.persisted` 복귀인지 확인하고, 중복 소리·날씨 요청 없이 복귀하는지 확인합니다.
5. 복귀 화면의 읽기 전용 안내와 저장 차단을 확인합니다. 새로고침 뒤에는 정상 저장 잠금 획득 여부를 확인합니다.
6. 시작 모듈 요청 실패를 재현해 안내를 확인한 뒤, 실패 원인을 해소하고 ‘다시 열기’가 한 번만 실행되는지 확인합니다.
