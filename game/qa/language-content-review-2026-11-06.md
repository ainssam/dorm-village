# 국어·영어 내용과 입력 경계 검토

2026-11-06 KST. 이 문서는 원래 작업 폴더의 내용·모형·view·음성 연결을 읽고 정적 자산을 대조한 기록이다. 런타임과 테스트 파일을 수정하지 않았고 브라우저를 실행하지 않았다. 실제 앱의 터치 완주, 음성 청취, 스크린리더 발음, 학습 효과는 별도 검수다.

## 판단과 구체적 보완 후보

정답·뜻풀이·자모 조합·역사 수치에서 명확한 오답이나 출시를 차단할 내용 결함은 찾지 못했다. 국어는 문맥별 맞춤법을 설명하고, 소리 없는 **첫소리** ㅇ과 받침 ㅇ을 구분하며, 한 음절을 모두 사전 낱말이라고 부르지 않는다. 한글 창제1443/간행1446·처음28자/오늘날 기본24자도 구분한다. 영어는 두 정중한 주문과 두 길 묻기 표현을 모두 인정한다.

| 항목 | 근거 | 영향·우선순위 |
| --- | --- | --- |
| 역할대화 선택 그룹의 접근성 이름이 단계와 다름 | `dist/english/view.js`의 `renderRoleplay()`에서 항상 `aria-label="내가 할 말 고르기"`를 사용한다. 음료 그림 찾기와 이동 방향 선택에서도 그대로다. | 보이는 안내와 정답 처리는 맞지만 보조공학에는 잘못된 과제를 설명한다. 각각 ‘주문한 음료 그림 선택’, ‘안내에 맞는 움직임 선택’으로 단계에 맞게 바꿀 작은 접근성 수정 후보다. |
| 일부 영어 구간의 언어 표시 누락 | `dist/english/view.js:81`의 완성 문장 `.english-answer`와 `:103`, `:105`, `:108`의 한국어 접두어+영어 카페 대화, `:112`의 순번+영어 길 안내에는 `lang="en"`이 없다. `:128`의 다섯 표현 영어 문단에는 이미 있다. 문장 조각·transcript·그림책 문장·예문·대화 선택지의 영어 span에도 있다. | 완성 문장은 해당 p에, 혼합 카페 대화·순번이 붙은 길 안내는 영어 부분 span에만 언어를 지정할 작은 수정 후보다. 실제 스크린리더 발음 오류를 관측한 근거는 아니다. |
| `some water` 설명의 정밀도 | `dist/english/content.js` 문장5: ‘some water는 물을 조금 달라는 뜻이에요.’ | 정답은 맞다. 명사구 자체를 요청 표현으로 설명하고 양을 ‘조금’으로 단정한 낮은 우선순위 문구다. ‘some water는 양을 딱 정하지 않고 물을 말할 때 써요’처럼 정밀화할 수 있다. 내용 차단 문제로 확대하지 않는다. |

길 묻기의 두 번째 선택 문장에는 별도 음성 clip이 없다. 시작 단계 소리 버튼은 첫 번째 질문을 읽고, 두 선택 뒤에는 공통 길 안내가 나온다. 모든 인쇄 문장을 소리로 제공한다고 주장하면 안 되지만, 해당 버튼의 transcript와 실제 연결 clip이 서로 다른 결함은 아니다.

## 내용·자산 대조

- 음성 manifest49항목의 normal/slow98파일이 모두 존재한다. 낱말/예문24·문장6·그림책4·일상표현5·경로1의 **40개 내용 연결**과 manifest text가 일치한다. 카페·남은 길안내 문구는 view 연결을 별도로 읽었다. 파일 존재와 텍스트 대조는 디코딩·실제 발음 청취의 증거가 아니다.
- `word-cards.webp`를 직접 보아12칸의 순서와 낱말을 대조했다. 투명한 물/흰 우유, 학교 교실/도서관, 노란 꽃/파란 연필을 구분한다. 예문의 사과2개 등은 그림이 아닌 별도 상황으로 명시한다.
- 그림책4장의 로컬 이미지를 직접 보았다. 책상 위 파란 연필→빈 책상과 의자 아래 연필→아래를 살펴봄→찾은 연필과 별 그림의 문장·alt가 맞는다. 화면에서의 크기·CSS crop 검수는 아니다.

## 음성·수명 검수 경계

소리는 사용자의 듣기 버튼에서만 시작한다. view의 모든 학습 상태 변경은 기존 소리를 중단하며, 탭·책장·문제 이동 뒤 transcript를 초기화한다. 비동기 재생은 generation과 현재 audioNodes를 확인하므로 오래된 실패가 새 화면의 글자를 덮지 않는다. 실패하면 정답을 변경하지 않고 transcript를 펼친다. blur/hidden/닫기에서 중단하고 재열기는 새 학습 세션이다. 이들은 코드 검토 사실이며 실제 기기에서의 청취 합격은 아니다.

마을 ‘소리’ 버튼의 접근성 이름은 ‘배경음 켜기/끄기’이고 `gameAudio.enabled`는 배경음 선택이다. 영어의 명시적 듣기 버튼은 같은 output을 사용하되 배경음 꺼짐과 독립적으로 unlock한다. 배경음 꺼짐을 영어 음소거라고 가정한 테스트를 작성하면 안 된다. 각 듣기의 ‘소리 멈추기’와 글자 보기·닫기를 실제로 확인한다.

현재 기존 근거는 탭/대화/책장 진도 보존과 일부 활동 완료다. 위 전체 국어22문항·영어12듣기/6문장·역할대화8경로·사전/책/표현을 실제 브라우저에서 새로 끝냈다고 이 문서로 주장하지 않는다. 통합 담당자의 별도 실행 결과를 기다린다.

정정 기록: 처음 작성한 표는 다섯 일상표현의 영어 문단에도 언어 표시가 없다고 잘못 기술했다. 현재 `renderDictionary()`의 `el('p',p.line,{lang:'en'})`를 재확인해 해당 주장을 제거했다. 수정 후보는 위에 지정한 완성 문장·카페 대화·길 안내 구간으로 한정한다.
