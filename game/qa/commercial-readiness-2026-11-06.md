# 상용 품질과 상업 이용 조건 검토 · 2026-11-06

검토 기준은 **힐링·휴식·즐거움과 놀이 속 작은 배움**이다. 현재 작업은 무료 공개 앱의 품질 향상이며 결제·광고·구독 서비스를 시작하는 작업이 아니다. 기술 검수 통과를 판매 권리, 실제 이용자의 재미, 수익성 검증으로 확대하지 않는다.

## 현재 판단

무료 공개 개선 작업을 계속할 수 있다. 다만 **유료 상품으로 바로 판매 가능한 상태라는 판정은 보류**한다. 구체적으로 도름이 자산의 별도 상업 이용권과 선택형 날씨 API의 상업 서비스 조건이 남는다. 이를 이유로 개발·무료 공개 검수를 중단하거나 서비스 구독을 구매하지 않았다. 라이선스 고지를 바꾸거나 자산을 임의로 재라이선스하지 않았다.

## 모토에 맞는 품질 개선 기준

[기존 상용 앱 6종 비교](market-benchmark-2026-11-01.md)는 공식 제품 문서 비교이며 직접 플레이한 결과는 아니다. 이번 개선에서는 다음 기준을 실제 조작으로 확인한다.

| 사용자에게 남을 경험 | 적용할 기준 | 기존 기능에서 우선 볼 곳 |
| --- | --- | --- |
| 한 번 만져도 기분 좋은 결과 | 첫 결과물이 안내문·예시와 겹치지 않고, 실수를 되돌릴 수 있다. | 수학 새 칠판의 밑그림 겹침, 그림 보관 뒤 편하게 닫기. |
| 실패가 부담 없는 놀이 | 입력과 판정이 읽히고, 도움 사용에 벌점이 없으며 재입장 없이 다시 할 수 있다. | 클라이밍 완료 후 재연습, 패스/던지기 결과와 다음 행동. |
| 장소마다 다른 발견 | 음악은 소리, 과학은 조건 변화, 공방은 만든 물건처럼 실제 행동·결과가 다르다. | 모든 공간을 같은 퀴즈·출석·점수 방식으로 바꾸지 않는다. |
| 쉬는 동안 방해받지 않기 | 관람·의자·풍경은 점수 없이도 완결되며, 언제든 나갈 수 있다. | 전체 비행·항해의 중단/복귀, 동작 줄이기, 안내 패널의 가림. |
| 내가 한 일이 다음 경험으로 이어지기 | 만든 것·보낸 것·발견한 것을 다시 찾고 사용하며, 소비/삭제 결과를 이해한다. | 편지의 친구별 답장, 사진 한도·삭제와 집 액자 연결, 수집 재료의 쓰임. |

추가 메뉴 수, 접속 보상, 오래 붙잡는 타이머를 판매 품질의 대체 지표로 삼지 않는다. 실제 첫 이용자의 자발적 재시도, 다시 방문하고 싶은 장소, 막혔던 지점을 관찰해야 재미와 재방문을 판단할 수 있다. 이번 내부 에이전트 검토가 그 이용자 관찰을 대신하지 않는다.

## 독립 코드 검토

- 클라이밍 재연습: `climbing-controller.js`가 기존 `stop('retry')`의 지지된 역동작을 사용하고, 완료 후 돌아온 `stopped` 상태에서 방법 변경과 명시적 재시작을 허용하는지 확인했다. `climbing-session.js`는 `exitRequested`일 때만 매트로 내려오므로 반환과 퇴장을 구분한다. 새 연습의 중단 이유 초기화와 동일한 상태 문구의 매 프레임 재할당 억제까지 검토했다. `tests/climbing-replay.test.mjs` **3/3 재실행 통과**. 이 테스트의 접촉 증거는 모의값이다. 실제 Meshy 관절의 수동 6칸→역순 반환→쉬운 길 6칸→하차는 [담당자 브라우저 기록](2026-11-06-play-sports-quality.md)으로 별도 구분한다.
- 수학 첫 칠판·미술 하단 닫기: 새 문서만 `baseVisible:false`로 시작하고 기존 저장 상태의 `true/false`를 그대로 복원하는 경로를 검토했다. `tests/math-board-start.test.mjs` **2/2 재실행 통과**. 미술의 `returnButton:true`는 기존 닫기/정리 경로를 사용하며 그림 위에 겹치는 버튼을 만들지 않는다. 실제 작은 화면의 보관→닫기와 새 칠판의 산출물 가시성은 브라우저 검증 결과와 별도로 구분한다.
- 사진·편지: 삭제 확인을 열어 둔 상태에서 새 사진을 액자로 만들면 이전 확인이 남아 작동하지 않는 흐름을 지적했다. 담당자가 새 저장·벽 변경 시 확인을 취소하도록 수정했다. 저장 실패에도 기존 편지 내용은 읽을 수 있게 하되 읽음 상태는 보존하도록 제안하고 반영을 검토했다. `tests/living-memory-actions.test.mjs` **6/6 통과**: 삭제 확인/취소·선택 변경, 실패 후 재시도, 벽 변경, 확인 중 새 액자 저장, 편지 보내기/읽음 실패와 중복 선물 방지, 친구×마음 9개 답장. 실제 reducer를 사용하고 DOM/사진 preview는 모의 구현이므로 실제 3D 촬영·터치 배치 증거를 대신하지 않는다.
