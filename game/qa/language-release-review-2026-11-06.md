## 검토 기준과 보완

기존 활동이 실제로 끝까지 작동하고, 틀렸을 때 도움을 받아 다시 해볼 수 있는지 확인한다. 문항 수나 보상을 늘리는 대신 읽기·듣기·그림·짧은 대화 중 원하는 방식으로 천천히 사용할 수 있게 한다. [실행 계획](language-quality-plan-2026-11-06.md)과 [내용 검토](language-content-review-2026-11-06.md)를 바탕으로 실제 입력 담당과 별도 화면 검토자가 교차 확인한다.

첫 전체390px 실행에서 국어 맞춤법8·자모6·뜻풀이8과 읽기/역사·이야기3편, 영어12듣기·6문장·카페4/길안내4경로·사전12/그림책4/표현5·짧은6낱말 복습을 확인했다. 정답은 저장소 내용을 읽어 실제 버튼을 고르는 QA solver다. 사람의 학습 효과·난이도·재미를 측정한 결과로 세지 않는다. 초기 국어 묶음은 하네스가 보조 출처 펼침까지48px을 요구해 진입에서 멈췄으므로 별도 보충 실행으로 완주했다. 실제 보조 summary는47px, 주요 답/행동은48px 이상이었다. 실패한 묶음을 처음부터 통과했다고 바꾸지 않는다.

| 발견 | 보완 방향 |
| --- | --- |
| 영어 길 안내의 큰 지도가 첫 질문과 선택지를 아래로 밀어냄 | 처음 질문에는 답할 표현을 먼저 제시. 길 안내 단계에서 실제 위치 지도를 보여 주고, 이동 선택을 소리 조작보다 앞에 둠. 작은 화면 지도는 글자·방향을 유지하며 공간을 줄임 |
| 음료 그림/길 이동 단계에서도 접근성 그룹 이름이 ‘내가 할 말 고르기’ | 실제 단계의 ‘주문한 음료 그림 선택’·‘안내에 맞는 움직임 선택’으로 구분 |
| 완성 영어 문장과 한국어 접두어가 섞인 대화 줄에 영어 언어 표지가 없음 | 완성 문장은 `lang=en`, 혼합 줄은 영어 부분만 별도 span으로 표시. 기존 그림책·다섯 표현의 올바른 표지는 유지 |
| some water를 명사구 자체가 요청이고 양이 적은 것처럼 설명 | 정중한 요청은 May I have…?로 설명하고 some water는 양을 딱 정하지 않는 표현으로 정밀화 |
| 새 대화 단계에서 없어진 선택지 대신 장소 메뉴에 초점이 돌아감 | 같은 선택지가 남으면 유지하고, 사라졌으면 새 단계의 대화 선택지를 먼저 찾음 |
| 오답 설명이 선택적 소리 조작 아래 또는 작은 창 밖에 남음 | 설명 뒤에 역할대화 소리 영역을 두고 매 화면 갱신/종료에 정리. 오답 설명이 창 밖일 때만 가까운 쪽으로 즉시 스크롤하며 선택 버튼 초점은 유지 |

실제 핵심 사용을 확인한 뒤에도 [별도 화면 검토](language-visual-independent-2026-11-06.md)에서 다음 행동 발견 문제를 찾았다. 입력 성공만으로 화면을 합격시키지 않고, 보완 후 작은폰·폰·가로·태블릿·PC를 다시 대조했다. 작은320px의 긴 첫 카페 문장은 보통의 스크롤을 사용하며 모든 안내·선택지를 첫 화면에 한꺼번에 맞췄다고 주장하지 않는다.

## 최종 검수와 범위

동결 소스의 `npm run check`와 **364/364 회귀 검사**가 통과했다. 실패·취소·건너뜀0, 전후 `dist/`·`tests/` **939파일 SHA-256 동일**이며 [소스 명세](tested-source-language-2026-11-06.json), [문법 로그](language-check-final-2026-11-06.txt), [회귀 로그](language-test-final-2026-11-06.txt)에 기록했다. 기존 학습 진도·오디오·저장 검사를 유지하며 이 변경에 테스트 개수를 늘리는 것을 목표로 삼지 않았다.

[역할대화 DOM 검수](language-roleplay-dom-summary-2026-11-06.json)는320×568,390×844,844×390,768×1024,1440×900의5/5다. 실제 UI·모형·CSS와 입력으로 상태 전환·오답·그림/글자·초점을 확인하되 `game.js`를 막은 독립 component 검수다. 관련8파일 불변을 전체3D 검수로 확대하지 않는다.

최종5개 실행의 **854개 런타임 파일은 서로 같고 각 실행 전후·전체 검사 명세와 모두 일치**한다. 정상4개 실행은 페이지·콘솔·HTTP·예상 밖 요청 오류0, 자동 음성 요청0이다.320px의 의도적 실패에서는 예상 요청 실패2건과 대응 콘솔 `ERR_FAILED`2건을 별도로 기록했으며, 앱 예외·HTTP 실패·예상 밖 오류는0이었다. 이를 모든 실행 ‘오류0’으로 뭉뚱그리지 않는다. [실제 앱 상세](language-quality-review-2026-11-06.md)를 따른다.

실제 지도에서 교실을 고른 뒤 충돌/가시선을 확인한 가까운 위치를 준비하고 실제 행동 버튼/E로 진입한다. 전체 보행·자유 탐색을 처음부터 사람이 해본 증거가 아니다. DPR1·SwiftShader·3D 렌더 샘플링을 사용하며 성능 수치로 해석하지 않는다. 영어 듣기 기본 경로는 글자를 보며 진행했고 음성 자동재생은 없었다. 실제 음성·스피커 청취, 실물기기/Safari/스크린리더, 학습 효과·장기 재미는 이번 검사와 구분한다.
