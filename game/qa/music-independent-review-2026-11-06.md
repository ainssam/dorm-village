# 음악 개선 독립 검토 · 2026-11-06

**판정: 최종 변경 범위 승인. 차단 이슈 없음.** 별도 검토자가 소스와 새 회귀를 읽고 초기 오디오 실패 경로를 실제 UI/컨트롤러/오디오 모듈의 CPU 모형으로 독립 재현했다. 최종 퀴즈 전환은 소스·회귀를 재검토했다. 통합 전체 검사, 실제 3D 앱 또는 청취 승인을 뜻하지 않는다.

- 실패 처리는 현재 요청 토큰과 선택에만 적용된다. 늦은 decode/unlock 실패가 새 선택을 정지시키지 않는다.
- 음량은 요청을 만들지 않고 현재 gain만 바꾼다. 대기 중인 재생도 최신 값으로 시작한다. 실패 source/gain 정리 회귀를 추가했다.
- ‘멈추기’와 처음부터 재생/반복 안내는 실제 동작과 일치한다.
- 초점을 가진 답만 재렌더 후 같은 답으로 복구한다. `preventScroll:true`와 종료 가드를 유지한다.
- Next의 초점 소유권을 비활성화/숨기기 전에 확인한다. 성공한 전환만 새 첫 답 또는 보이는 Restart에 기본 focus를 준다. 모델·공통 render·Retry·닫기는 바꾸지 않는다.
- 회귀는 모든 6문항의 보이는/활성/연결된 초점 대상, 정상 Tab을 위한 목적지, 비초점 호출, 무응답 Next, 닫힌 답/Next 콜백을 다룬다. 비활성 Next를 인위적으로 초점 잡던 초기 시험 모형은 실제 가능한 Retry/활성 Next 순서로 고쳤다.

최종 관련 검사 **31/31**와 실제 Chromium 구성요소 **3규격**의 범위는 [회복 보고서](music-playback-recovery-2026-11-06.md)에 기록했다. 기존 음악 파일·악기 자산·출처 고지는 보존했다. 원래 언어 변경은 이 격리 변경에 포함하지 않았다.
