# 도름마을 공개 출시를 위한 상용 제품 비교

검토일: 2026-11-01. 범위: 공식 제품 페이지, 개발자·배급사 스토어 설명, 공식 지원 자료를 읽은 **문서 기반 비교**. 아래 게임들을 이번 검토에서 직접 플레이하지 않았다. 제품 설명은 제공자가 설명한 설계 의도를 확인하는 근거이며, 실제 재미·교육 효과·힐링 효과·시장 성공을 입증하는 자료로 사용하지 않는다. 사용자 리뷰·매출·다운로드 수·홍보 문구로 도름마을의 품질 합격을 추정하지 않는다.

도름마을의 합격 판정에는 별도의 실제 브라우저 이용 흐름, 모바일 조작, 오류·저장·복귀 검증이 필요하다. 아래 적용 제안은 현재 기능이 없다는 단정이 아니라, 기존 구현을 판단하고 부족한 부분만 보완할 기준이다.

## 비교에서 얻은 판단

공간의 개수보다 **이곳에서 무엇을 하는지 바로 알고, 한 번 조작해 변화가 보이고, 다시 해보거나 편하게 떠날 수 있는지**가 우선이다. 조용한 휴식 공간은 점수나 과제를 만들지 않아도 된다. 창작 공간은 사용자가 만든 결과, 발견 공간은 새로 알게 된 것, 놀이 공간은 조작과 피드백이 방문 이유가 되어야 한다. 모든 곳을 같은 설명창·퀴즈·점수 방식으로 구성하면 장소의 의미가 약해진다.

## 놀이공원에 대한 적용 우선순위

### P0 — 공개 전에 실제 이용 흐름으로 확인하고 고칠 것

1. **놀이의 약속과 실제 행동 일치.** 입구에서 무엇을 하는지, 직접 조작인지 편하게 타는 것인지, 어떻게 끝내는지 한눈에 알려야 한다. ‘카트 경주’라고 안내한 뒤 차에 앉기만 하는 등 이름과 실제 행동이 어긋나는 곳이 있다면 내용이나 이름을 수정한다.
2. **입장 → 첫 행동 → 결과 → 재시도/복귀가 끊기지 않기.** 카트·범퍼카·인형뽑기·물고기 뜰채 각각 키보드와 터치로 끝까지 수행한다. 안내를 닫은 뒤 조작이 사라짐, 잘못 잡은 포인터, 페이지 스크롤, 장면 이동 뒤 입력 잠금 같은 고장은 출시 차단 사유다.
3. **조작 결과를 납득할 수 있기.** 인형뽑기는 집게와 목표의 위치 관계, 물고기 잡기는 뜰채가 영향을 주는 범위, 카트는 현재 방향·속도·코스 경계·완주 상태를 읽을 수 있어야 한다. 실패했다면 무엇을 바꿔 다시 하면 되는지 알 수 있어야 한다. 무작위 결과를 정교한 기술 게임인 것처럼 설명하지 않는다.
4. **언제나 편하게 나가기.** 휴식 놀이기구에는 찾기 쉬운 내리기, 참여 게임에는 일관된 그만하기·다시 하기를 제공한다. 회전·낙하·가속 연출은 동작 줄이기 설정을 존중하는지 확인한다. 중단해도 기록·월드·입력이 망가지면 안 된다.
5. **작은 화면에서 핵심 조작 유지.** 설명·조작·진행 상태가 겹치지 않고, 손가락으로 가려져도 핵심 대상이 보이며, 버튼이 실제로 눌리는지 본다. 기본 입력과 대체 입력을 실제로 각각 수행한다.

### P1 — 기존 기능을 더 쓸 만하게 만드는 개선

- **휴식과 도전을 구분한다.** 회전목마·관람·풍경 감상은 쉬는 경험, 카트·인형뽑기·뜰채는 직접 하는 놀이로 안내한다. 모든 탑승에 점수나 타이머를 붙이지 않는다.
- **연습을 저렴하게 만든다.** 카트는 낮은 속도·자동 가속 등 한 가지 보조만으로도 진입 부담을 줄일 수 있다. 인형뽑기와 뜰채는 짧은 조작 힌트와 즉시 재시도를 우선한다. 제한 횟수·기다림·화폐 비용은 추가하지 않는다.
- **기억할 결과를 남긴다.** 기존에 저장 구조가 있다면 최근 만든 것·발견한 것·즐긴 놀이의 작은 기록으로 되돌아갈 이유를 만든다. 새 계정·서버·랭킹까지 만들 필요는 없다. 현재 브라우저 저장이라는 실제 범위는 솔직하게 알린다.
- **쉬운 시작과 선택적 깊이.** 첫 결과는 한두 번의 행동으로 얻고, 숙련을 원하는 사람만 조준·속도·조합을 더 탐색하게 한다. 처음부터 여러 조작을 동시에 익히게 하지 않는다.
- **공간의 빈 곳에 목적을 준다.** 쉴 자리·사진 구도·작은 발견·다음 놀이의 시각적 안내가 유효하다. 의미 없는 장식·건물·새 모달을 늘리지 않는다.

### P2 — 후속 사용자 관찰 후 판단할 것

- 선택형 짧은 산책 추천, 개인 창작물·발견 모음, 기존 활동을 연결한 작은 테마 경로. 현재 출시의 안정성을 해치면서 새 시스템을 만들 이유는 없다.
- 실제 첫 사용자에게 ‘지금 무엇을 할 수 있는지’, ‘어디서 그만두려 했는지’, ‘또 해보고 싶은 활동이 무엇인지’를 물어보고 관찰한다. 내부 검토만으로 ‘재미가 입증되었다’고 말하지 않는다.

## 피할 것

- 매일 접속하지 않으면 손해 보는 연속 출석, 소멸 보상, 에너지·입장권, 의미 없는 화폐 반복 수집. 편안함이라는 목적과 충돌하기 쉽다.
- 모든 공간에 같은 퀴즈·점수판·칭찬 문구를 반복하는 방식. 실제 행동이나 배움이 없는 ‘콘텐츠 수’는 품질 근거가 아니다.
- 상용 게임의 IP·캐릭터·음악·외형 복제. 비교 대상에서 배울 것은 조작·피드백·회복·진전의 구조다.
- 온라인 랭킹·채팅·상점·새 저장 백엔드를 이번 검토의 기본 해법으로 도입하는 것. 현재 경험을 완성하는 데 필요한지 먼저 판단한다.
