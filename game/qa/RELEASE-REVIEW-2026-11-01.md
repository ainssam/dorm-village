# 도름마을 공개 개선판 · 2026.11.01.1

최종 판정: **공개 배포 기준 합격 — 확인된 미해결 P0/P1 없음.** 아래의 직접 실행 근거, 파일 해시 대조, 독립 리뷰를 합쳐 판정했다. 모든 메뉴가 열린다는 사실과 모든 놀이의 재미·깊이를 입증했다는 주장은 구분한다.

## 무엇을 바꿨나

- 뜰채: 조준이 실제로 필요한 무제한 연습, 네 빛깔 모으기, 선택하는 50초 도전, 결과·즉시 다시 하기. 작은 휴대폰에서 연못을 가리지 않도록 패널을 줄이고, 한 손가락으로 이동하며 다른 손가락으로 잡는 조작을 고쳤다.
- 카트·범퍼카: 느린 연습/조작 도움, 한 바퀴 도전·기록·즉시 재시도, 세 곳을 찾아가는 짧은 범퍼카 놀이. 상단 안내를 하단 가림으로 잘못 계산해 차량·코스터가 아주 작아지던 카메라 문제와 스틱/퇴장 버튼 겹침을 수정했다.
- 국어·영어: 탭을 오가도 해당 시간의 진도 유지. 이야기 세 주제의 순서와 이유 질문, 지도에서 실제 확인할 수 있는 네 가지 관찰을 제공한다.
- 체육의 실제 발사: 새 도름이의 분리된 참조 손·발 좌표를 경기장 좌표로 바르게 바꿨다. 양궁·빛 표적에서 화면은 열려도 발사가 거절되던 원인을 수정했으며 판정 기준과 원본 모델은 유지했다. 실제 제작 모델/연결된 학교/장비의 발사와 퇴장을 회귀로 확인한다.
- 학습 완료를 막던 오류: 보건실의 정답 선택지 태그 누락과 수식 입력기의 MathLive 초기화 순서를 고쳤다. 그림·수식은 저장 후 전체 새로고침 복원과 실제 PNG 내려받기를 확인했다.
- 낚시: 감기 동작이 끝난 뒤 손을 놓을 때 생기는 클릭이 결과 화면의 재시도로 처리되지 않도록 고쳤다. 결과를 읽고 새로 누를 때 다시 시작한다.
- 생활: 레시피별 요리 설명을 실제 모형과 맞추고 요리 화면 중복 그리기를 제거했다. 텃밭에서 물주기·수확을 이어 할 수 있으며, 도서관은 보이는 원 가까이에서 책을 집고 배달할 수 있다.
- 매일 게시판: 검토한 60개 ‘오늘의 작은 발견’을 한국 날짜에 따라 순환한다. 짧은 읽을거리·마을 놀이·마음 질문과 최근 7일 다시 읽기를 제공한다. 실시간 뉴스나 매일 새로 집필하는 피드는 아니다.
- 첫 경험·디자인: 기분별 활동 찾기, 실제 메뉴 이름 검색, 시작 추천, 파스텔 화면·가독성·닫기/돌아가기. 놀이터 꽃밭, 간판 대비, 체육관 시작 위치를 개선했다. 악기·체육 등 실제 3D를 보여 주는 화면의 투명 배경을 보존하도록 공통 테마의 우선순위를 낮췄다. 낮은 가로 화면에는 연주 화면과 조작부를 나란히 배치했다. 공통 돌아가기 버튼은 일반 학습창에만 적용한다.
- 브랜드: 원래 Meshy 도름이를 참고한 파비콘·앱 아이콘·카카오톡 1200×630 홍보 이미지와 공유 메타. 그림은 홍보 일러스트이며 실제 플레이 화면으로 표시하지 않는다.

이전 공개판에서 도입한 관절 보행과 원본 `doreumi-desktop-pet`의 16개 동작은 유지한다. 춤·인사·점프는 동작 메뉴에서 고를 수 있다.

## 품질 판단의 경계

공식 소개·지원 문서 6개 앱/9개 출처와 비교해 목표/반응/즉시 재시도, 자유 탐색, 부담 없는 복귀를 개선했다(`market-benchmark-2026-11-01.md`). 상용 앱을 직접 장기간 플레이한 비교나 실제 이용자의 재미/학습 효과 실험은 아니다.

마을에는 짧은 게임, 만들기·관찰, 감상용 놀이기구가 함께 있다. 고정 동작으로 공을 굴리는 메뉴는 축구 경기로 설명하지 않는다. 과학·요리는 단순화된 모형이고 실제 조리 안내를 대신하지 않는다. 일부 채소의 활용처, 정해진 편지 문구, 카페의 먼 첫 시점 등은 확장 여지가 있다. 결제·출석 압박·매일 접속을 요구하는 보상은 추가하지 않았다.

화면 크기와 touch를 설정한 Chromium·소프트웨어 WebGL 검증이다. 실물 iPhone/iPad/Android·Safari의 GPU 성능, 스피커 음질/음성 청취, 실제 카카오톡 앱의 캐시 갱신은 확인하지 않았다. 긴 QA는 그리기만 간헐적으로 실행하는 하네스를 쓰며, 시각 캡처 중에는 정상 그리기를 복원한다. 게임의 시간·입력·점수·완료 조건을 빨리 돌리거나 결과를 직접 넣지 않는다. 하네스는 제품에 포함되지 않는다.
