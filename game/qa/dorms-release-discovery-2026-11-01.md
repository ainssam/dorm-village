공식 주소는 연결된 `ainssam/dorms-daily` README가 도름스를 `https://dorms.school`로 명시한 것과 공식 공개 사이트로 교차 확인했다. 도름마을 GitHub main, Vercel production 배포 및 공개 버전은 앞선 2026.10.25.2 출시 이후 바뀌지 않았다.

도름스는 외부 앱을 소개하는 별도 커뮤니티다. 도름마을 Vercel 갱신만으로 도름스 앱 목록에 등록되지는 않는다. 연결된 저장소 검색과 두 Vercel 계정의 프로젝트 목록에서 도름스 포털 소스/프로젝트는 발견하지 못했다. 이는 접근 가능한 목록의 결과이며, 포털 저장소가 존재하지 않는다는 뜻은 아니다.

## 앱 등록과 공개 조건

공개 상태에서 앱 등록 페이지는 다음 안내를 표시한다.

> 교사 인증이 필요해요. 앱 올리기는 교사 인증을 마친 선생님만 할 수 있어요. 인증을 완료하면 바로 작성할 수 있습니다.

따라서 앱 등록에는 도름스의 교사 인증 계정으로 로그인한 세션이 필요하다. 이 조사에서 사용 가능한 브라우저 프로필에는 도름스 로그인 상태가 없었다. 실제 등록 폼의 필수 필드, 공개 범위, 등록 버튼의 동작은 아직 확인하지 않았다.

공개 검색과 기본 목록에서는 기존 도름마을 상세 등록 주소를 찾지 못했다. 검색엔진 및 목록 첫 화면만으로 미등록을 확정할 수 없으므로, 게시 전 로그인 상태의 내 앱 목록 또는 사이트 검색으로 중복 등록 여부를 확인해야 한다.

공개 카탈로그의 실제 브라우저 검수에서는 `제목, 설명, 선생님 이름으로 검색` 입력란을 확인했다. 다만 입력 요소가 새로 고침 과정에서 교체되는 오류로 검색어 입력을 완료하지 못했다. 따라서 이 실행은 기존 등록 유무의 통과 증거로 사용하지 않는다. 등록 폼의 필수 필드명·대표 이미지 크기/용량·소개 글자수·최종 공개 옵션은 인증 화면을 통과하기 전에는 확인할 수 없었다.

공식 약관 제5조는 회원이 올린 앱·자료가 공개된다고 안내한다. 앱별 이용 권한 및 교사 인증/도름 열람 조건 설정이 존재한다는 안내도 있으나, 상세 설정 설명은 교사 인증 회원만 열람 가능하다. 이번 사용자 요청은 공개배포이므로 등록 화면에서 실제 공개 범위를 확인해야 한다.

## 자동 게시 관련 실제 운영 공지

2026-10-27 공식 공지 [도름스 약속에 AI 등 봇 활동 엄격 금지 규정을 추가했습니다](https://dorms.school/notice/community-rules-ai-bots)는 다음과 같이 적고 있다.

> 도름스가 사람 냄새 나는 커뮤니티가 될 수 있도록 AI 등 봇 활동을 엄격히 금지합니다. 글 작성 또는 댓글 작성 등은 선생님께서 직접 하시면서 도름스에 사람이 만들어 나가는 데이터만 기록될 수 있도록 도와주세요.

이 문구는 커뮤니티 게시를 자동 수행할지 판단할 때 참고해야 할 실제 운영 조건이다. 앱 소개 등록에 대한 별도의 예외는 공개 안내에서 확인하지 못했다. 코드 개선·GitHub 현행화·Vercel 공개 배포와, 도름스 커뮤니티의 최종 게시를 구분해 완료 상태를 보고하는 것이 정확하다. 게시용 URL·검증된 기능 설명·스크린샷·사용 안내까지 준비한 뒤, 교사 인증 계정에서 실제 작성자가 게시하는 경로를 마련할 수 있다.

## 오락실과의 구분

오락실은 공식 설명상 초·중·고 교과의 학년·과목·단원으로 찾는 교육 게임 모음이다. `게임 등록`은 [게이미피케이션 교육 협업 공간](https://dorms.school/collaboration?project=pub-2eb69ca5-565a-417d-9bb9-84c34fd2fa97&from=arcade&make=1)으로 연결된다. 도름마을 전체는 산책·휴식·창작·놀이를 아우르므로 일반 앱·자료 목록 등록과 오락실의 교과 게임 등록을 동일하게 취급하면 안 된다. 사용자가 특별히 오락실 등록을 요구한 것은 아니므로 일반 앱 등록이 직접적인 공개 경로다.
