# 도름마을 교실·학습 공간 출시 전 검토

검토일: 2026-11-01. 범위: 현행 `game/dist`의 실제 콘텐츠·모델·뷰·연결된 활동. 과거 QA 보고서와 README의 통과 기록을 이번 검토의 실행 증거로 사용하지 않았다. 제품 코드는 수정하지 않았다. 로봇·요리·균형·도서관은 하위 에이전트의 독립 소스 검토와 현행 모델 실행을 합쳤다.

## 판정

학습 공간은 단순 장식만 있는 상태가 아니다. 진자 실험, 수식·분필 칠판, 자유 그림, 로봇 공방은 직접 조작→관찰/산출물→재탐색의 이유가 있다. 국어·영어도 각각 여러 활동과 정확성 출처를 갖췄다. 그러나 **학습 탭을 바꾸면 풀던 진행이 사라지는 문제와 요리의 잘못된 인과 설명은 출시 전 수정할 P1**이다. 사회실과 별도 이야기/낱말 활동의 깊이는 다른 공간보다 현저히 낮다. 전체 공개 출시의 합격은 본 보고서만으로 선언할 수 없으며 모바일·오디오·저장·전 공간 이동 검증을 함께 통과해야 한다.

이번 범위에서 확인한 P0는 없다. 보건 퀴즈의 생활습관 내용, 국어 맞춤법·사전·훈민정음 설명, 이차함수·진자·돌림힘·갈톤보드의 기본 수학/물리 내용에서는 소스상 명백한 사실 오류를 찾지 못했다. 출처 링크의 이번 날짜 재열람까지 수행한 것은 아니므로 기존 콘텐츠의 `verifiedOn`을 이번 사실 확인 날짜로 승격하지 않는다.

## P1: 출시 전 수정할 사항

### 1. 사전을 찾아보는 것만으로 풀던 문제 진행이 초기화됨

- 근거: `dist/korean/view.js:111–112`의 `reset`, `setTab`. 탭만 바꿔도 세 세션과 사전 위치를 전부 새로 만든다.
- 영어도 `dist/english/view.js:135`의 `setTab`에서 듣기·문장·역할놀이·사전/책 위치 전부 초기화한다.
- 사용자 흐름: 문제를 풀다 뜻 확인→사전 탭→원래 활동. 이때 풀던 문제·조각·대화 상태가 사라져 탐색을 벌주는 구조다.
- 수정: 열린 학습실 안에서는 각 탭 세션과 사전/책 위치를 유지. '처음부터 다시'만 해당 활동을 초기화. 새로고침/닫기 저장 범위는 그대로 명확히 안내. 탭 전환 시 음성만 정지하고 음성 토글 상태는 별도 처리.
- 회귀 확인: 각 언어의 2번 문제로 이동→사전 열기→원래 탭. 문장 미완성 조각과 역할놀이 중간 단계도 유지. 재시작은 자기 탭만 초기화. 키보드 탭 이동과 정답 후 포커스 보존.

### 2. 코코아와 샐러드에도 팬케이크 같은 과혼합 원인을 적용함

- 근거: `dist/home/cooking-model.js:26`의 `evaluateCooking`.
- 기준 비율 코코아를 8바퀴 섞으면 '촘촘한 포근한 코코아', `texture:'dense'`, 섞임96/100. 실제 모델 호출로 재현.
- 첫 재료가0번이면 모든 레시피에 '가루나 채소를 먼저 담아 고르게 퍼졌어요', 아니면 '고르게 섞이기 조금 어려웠어요'를 부여. 현재 재료와 맞지 않는 문구와 실제 원인처럼 읽히는 단정이다.
- 수정: 코코아는 충분히 섞인 뒤 과혼합 벌점 제거. 레시피별 관찰 문구 분리. 순서는 '이번에 고른 순서'로 기록하거나 이 게임의 가정임을 결과 자체에 명시. 식품 과학 실험으로 과대 표현하지 않기.
- 회귀 확인: 코코아7/8/12바퀴 비교, 샐러드/팬케이크 각각 부족·적정·초과 섞기, 빈재료/초안 재개/다시 만들기.

### 3. 코코아 가열 안내가 실제로 변하지 않는 색을 보라고 함

- 근거: 같은 모델에서 코코아 `color`는 코코아 비중 `shares[0]`만 사용하고 열은 사용하지 않는다. `dist/home/cooking-controller.js:12`는 '변하는 색을 보고 꺼낼 때를 골라요', 결과는 '알맞게 색이 변함'.
- 수정: 코코아에서는 쌓인 열·세기×시간·농도를 비교하는 안내/결과로 통일. 가열로 색이 달라진다는 관찰을 약속하지 않는다. 팬케이크 갈변과 명시적으로 구분.

## 상용 앱 기준과의 비교

시장 담당 에이전트의 공식문서 조사에 따르면 [Toca Boca World](https://play.google.com/store/apps/details?id=com.tocaboca.tocalifeworld&hl=en_US)는 시간 제한/최고점수 없는 창작, 읽기 능력 차이를 고려한 터치 조작, 교실·카페·집의 역할놀이를 설명한다. [Townscaper](https://rawfury.com/games/townscaper/)는 직관적 도구와 즉시 보기 좋은 창작 결과를 강조한다. 직접 플레이/교육효과 실증 비교는 아니다.

이 기준에서 도름마을의 그림·수식·코딩·진자는 손으로 결과를 바꾸며 다시 시도할 이유가 있어 방향이 좋다. 반면 사회실 지도와 단발 퀴즈를 여러 개 늘려 '공간 수'만 확보하면 체감 품질은 낮다. 각 공간에 1–3분 안에 무엇을 해보고 어떤 결과를 얻는지 분명해야 한다. 휴식 공간에는 반드시 학습 성취를 요구하지 않아야 한다.
