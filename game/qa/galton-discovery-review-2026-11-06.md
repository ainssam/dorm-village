# 갈톤보드 · 조용한 발견과 비교

후속 통합: 아래는 분리 구현 당시의 범위를 보존한 기록이다. 이후 `2026.11.06.3`에 통합하여 전체364개 검사와 실제 앱3규격 검수를 완료했다. 최종 소스·기기 범위·공용 모달 후속 수정은 [출시 검토](galton-release-review-2026-11-06.md)와 [실제 앱 검수](galton-browser-final-2026-11-06.md)를 따른다. 이 문서의 독립 DOM 근거를 전체3D 근거로 바꾸어 읽지 않는다.

2026-11-06 KST. 별도 `feat/galton-discovery-2026-11-06` 작업 트리에서 구현했다. 공개판이나 수확 한 그릇 출시 브랜치는 수정하지 않았다. **현재 판정은 계약 검사와 실제 UI 모듈의 DOM/2D canvas 검수 통과이며, 통합 3D 앱 검수·전체 패키지 검사·배포 완료를 뜻하지 않는다.**

## 이용자에게 생기는 변화

처음에는 30개 구슬로 가볍게 시작한다. 기다리는 수·내려오는 수·도착한 수를 읽고 잠깐 멈췄다가 이어 볼 수 있다. 모두 도착하면 완료를 분명히 알리고, 실제로 가장 많이 모인 칸을 소개한다. ‘같은 수로 다시 보기’나 구슬 수 변경은 직전 완료 결과 하나를 비교표에 남긴다. 부분 실행은 완료 결과로 저장하지 않는다. 비교의 비율은 각 실험의 전체 구슬 수를 따로 기준으로 삼는다.

첫 설명은 구슬을 바라보는 짧은 안내다. 독립적인 좌우50% 선택8회·이항분포·실제 충돌 물리와의 차이는 접힌 설명에 보존한다. 가운데가 언제나 가장 많다거나 구슬을 늘리면 반드시 이론에 가까워진다고 주장하지 않는다. 결과표에는 반올림 때문에 합계가100%와 조금 다를 수 있음을 알린다. 점수·시간 제한·방문 보상·정답 퀴즈는 추가하지 않았다.

폰에서 읽기 전용 그림 위로 손가락을 밀어도 모달을 스크롤할 수 있다. 결과표는 실제 배포 CSS까지 적용한16px이고 조작부는48px 이상이다. ‘그림 속 구슬 움직임 감추기’는 이 canvas의 움직이는 구슬만 감춘다. 움직임 줄이기 설정이면 처음부터 선택되며 수량·결과는 그대로 읽을 수 있다. 뒤쪽3D 벽의 모든 모션을 끈다는 뜻은 아니다.

## 구현 경계

- `galton-discovery.js`는 기존 모형을 감싸는 세션 비교 계약이다. 시간 전진·임의 결과 생성·저장 쓰기를 하지 않는다. 완료 직전 클릭도 실제 `snapshot()`으로 판단하고, 다음 실험을 시작하기 직전에만 완료 결과를 방어적으로 복사한다.
- `galton-workshop.js`는 기존 `schoolView.galton`의 시간 흐름을 읽는다. 모형은 계속 학교 장면이 구동하며 view가 별도로 업데이트하지 않는다. 도구 소유자가 시뮬레이션별 WeakMap으로 비교 상태를 보관하고 닫기에서 동기적으로 멈춘다.
- 같은 보드를 닫았다 열면 현재/직전 결과를 유지한다. `school-floor-layout.js`와 `RoomManager`의 소유권상2층 world를 벗어나면 보드가 폐기되고, 새로고침도 새 모형을 만든다. 안내는 이 범위를 따른다.
- `galton.css`는 기존 style의 세 번째 import다. `.galton-workspace`/ID 범위로 후행 release CSS를 이긴다. `pan-y`는 갈톤 canvas만 적용하며 미술·분필 canvas는 바꾸지 않는다.
- 원래 `galton.js`, `galton-view.js`, 전역 저장 스키마와 버전 표시는 변경하지 않았다.

## 검토 중 수정한 실제 결함

독립 검토자가 그래프 캐시의 초기화 문제를 지적했다. 첫 구슬이 도착하기 전에는 모든 칸이0이므로, 합계와 칸 수만 캐시하면 ‘결과 지우기’ 뒤에도 내려오던 구슬 그림이 남을 수 있었다. 캐시에 진행 상태와 방출된 구슬 수를 포함해 초기화·정지의 그림도 갱신한다. DOM 검사는 첫 비행 중 정지→결과 지우기 뒤 canvas 해시가 빈판과 같은지 확인한다.

첫 DOM 실행에서는 초기 canvas 글자가 웹폰트 로딩 전에 그려져 빈판 비교가 달라졌다. 폰트 준비 후 view가 살아 있을 때 한 번 다시 그리도록 보완했다. 최종5규격과 작은 표 재확인에서 초기화의 픽셀 비교가 통과한다. 중간 실패 결과는 합격 자료로 승격하지 않는다.

원 검토의 ‘수량 표시12px’는 cascade를 놓친 오류였다. 실제 규칙은 style29의12px→style50의19px→release116의14px이다. 이 구현은 최종 computed style16px을 브라우저에서 확인했다. canvas 축 번호의 비트맵 축소와 DOM 글자 크기를 구분한다.

## 검증과 범위

`node --test tests/galton-discovery-contract.test.mjs tests/language-session-retention.test.mjs tests/math-board-start.test.mjs tests/subject-exploration.test.mjs` → **22/22 통과**. 이 중 독립 검토자가 작성한 새 갈톤7개는 다음을 확인한다.

- 실제 모형에서 초기30개·정확한8회 이항확률·총수 보존.
- 정지/닫기/재개가 원래 구슬 경로를 다시 뽑지 않음.
- 그리기 직후가 아닌 늦은 완료라도 새 실험 전에 실제 결과를 보관함.
- 30개와100개 비교 및100개 중1개만 도착한 중간 비율의 분모.
- 부분 실행·같은 수 재선택·잘못된 입력이 이전 완료 결과를 훼손하지 않음.
- 반환 배열을 바꾸어도 내부 기록이 보존되며 명시적 지우기 뒤 결과가 되살아나지 않음.
- 이미 시작된100개 실험을 도구가 처음 연결해도 초기30개로 덮어쓰지 않음.

[DOM/2D canvas 최종 결과](galton-discovery-dom-final-2026-11-06/results.json): **320×568,390×844,844×390,768×1024,1440×900의5/5 통과**, pageerror0, 검사 전후6개 모듈/CSS 해시 동일. 실제 production 도구와 기존 모형을 쓰되, 별도 모달 셸과 실시간 component clock으로 실행한 검수다. 학교 장면·보행·이동·3D 벽 모형의 통합 증거가 아니다.

- 터치4규격에서 canvas 위에서 시작한 CDP native swipe로 실제 모달 scrollTop이 증가했다. 조작48px 이상, 수량16px, 가로 넘침 없음.
- 모든 규격에서 실제 모형 시간으로30개 완료, 첫 비행 중 정지/초기화 canvas 비교,100개 부분 실행, 비교 분모, 닫기/재열기 보존,300개 선택/초기화를 확인했다. 390규격은100개 완료와 같은 수 다시 보기도 실행했다. **300개 완주는 이 DOM 실행 범위에 없다.**
- 768규격은 움직임 줄이기,1440규격은 키보드 Enter 시작·Esc 종료를 확인했다.
- 320규격은 RNG가 모두 왼쪽을 고르는 명시적 경계 fixture다.100.0% 및300/30개 비교표의 최대폭을 검사하기 위함이며 실제 무작위 분포 캡처로 세지 않는다. 나머지는 `Math.random`이다.
- 결과표의 행을 직접 보도록 캡처 위치만 보완한 [320 재확인](galton-table-detail-2026-11-06/results.json)은 같은 런타임에서 다시 통과했다. [작은 표 이미지](galton-table-detail-2026-11-06/320x568-300-table.png)에100.0%와 네 열이 넘치지 않음을 확인했다.
