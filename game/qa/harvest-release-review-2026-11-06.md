**명시한 기능·화면 출시 게이트 통과.** 검수판은 `2026.11.06.2`, 기준은 `40e3c6b`(이전 공개 런타임 `fe86624`)다. 이 기록의 코드 검수 완료를 Vercel 배포 완료로 대신 읽지 않는다. GitHub 병합과 공개 배포의 최종 식별자는 후속 배포 기록에 남긴다.

## 이용자에게 생기는 변화

토마토·호박·잎채소의 수확이 카페 휴식으로 이어진다. 원하는 채소 1개로 한 그릇을 준비하고, 한 번 수확한 2개로 내 몫과 친구 몫을 마련한다. 종류를 모두 모으거나 식사 횟수를 채울 필요가 없다. 준비 후 명시적으로 받기 전에는 재료를 쓰지 않고, 먹는 첫 입에서만 완성 음식을 한 번 소비한다. 기존 음료·빵과 같은 음식주머니를 사용한다.

그릇은 크림색 바탕에 재료별 색·조각 형태로 구분한다. 설명은 실제 보이는 조각·색과 식물의 열매/잎 관찰에 맞추며, 하지 않은 조리 과정이나 건강 효과를 주장하지 않는다. 선택할 때 필요한 정보와 준비·먹는 동안 작은 상태 안내를 나누어 음식과 캐릭터를 볼 수 있게 한다.

[구현 계획](../docs/harvest-use-next-cycle-2026-11-06.md)과 [저장 계약](harvest-use-contract-review-2026-11-06.md)을 기준으로 저장·제어, 화면, 3D 소품, 독립 회귀, 실제 브라우저 사용을 나눠 교차 검토했다.
