# 도름마을 출시 검수

## 목표와 디자인 방향
기존 놀이와 저장 호환을 보존하며 36개 장소와 각 상호작용을 브라우저에서 순회한다. 새 도름이는 ainssam/doreumi-desktop-pet의 마스터 메시·텍스처를 사용하고 마을의 기존 동작 좌표계에 맞춘다. 보행 동선과 카메라 가시성을 해치지 않는 낮은 식재, 길 가장자리, 해안 디테일로 빈 공간을 다듬는다. 비행기는 탑승구·지지면을 보존하면서 외피·창·도장·날개 디테일을 개선한다.

UI는 장면을 우선하고 주요 행동을 지도·가까운 활동으로 한정한다. 크림/잉크/세이지 색, 기존 한글 서체, 일정한 8px 간격과 44px 이상의 터치 영역을 사용한다. 처음 방문 시 조작과 로컬 저장을 짧게 안내한다. 설정에서 도움말·저장 안내·라이선스에 접근할 수 있도록 한다. 불필요한 반복 설명은 줄이고 키보드 초점·모바일 안전 영역·오류 복구를 검수한다.

## 검증 범위
브라우저의 소프트웨어 WebGL로 기능과 화면을 확인한다. 실제 모바일 GPU 성능은 이 환경에서 측정할 수 없으며 결과와 구분한다. 자동 순회에서 위치 설정용 테스트 브리지를 요청 가로채기로 주입하며 배포 파일에는 넣지 않는다.
