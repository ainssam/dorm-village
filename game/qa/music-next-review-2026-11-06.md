## 확인한 결함과 현재 상태

1. 감상 재생 실패 뒤 재생 의도가 남아 음량만 바꾸면 숨은 재요청/재생이 시작됐다. 독립 재현 후 격리 수정했다. 현재 요청/선택에만 실패를 적용하며, 음량은 재시도하지 않는다.
2. 퀴즈 답의 재렌더와 Next의 비활성화/숨김이 키보드 초점을 끊었다. 실제 Chromium 3규격에서 재현하고 소유한 초점만 답·새 첫 답·Restart로 잇도록 수정했다.
3. 감상은 이어듣기 대신 처음부터 재생한다. 동작을 유지하며 버튼을 ‘멈추기’로 바꾸고 반복/처음부터 재생을 안내했다.

세 런타임 파일과 새 감상 13건/초점 6건 회귀로 범위를 제한했다. 관련 검사 31/31, 실제 Chromium 구성요소 3규격 통과 및 독립 승인은 [회복 보고서](music-playback-recovery-2026-11-06.md)에 기록한다. 실제 3D 음악실 판정은 아직 올리지 않는다.

## 이번에 확인한 내용

- 실제 퀴즈 UI의 6문항 모두에서 오답 설명 → 다시 생각하기 → 정답 → 다음을 실행했다. 완료·처음부터·닫기 후 잠금 해제와 벽 보드 0번 복귀가 정상이다. 오답 후에도 다음으로 갈 수 있는 것은 강요 없는 탐색 방식이며 오류로 세지 않았다.
- 악기 조작에는 소리 정지/닫기, blur/숨김 시 중단, 늦은 음성 준비 무효화가 구현돼 있다. 감상도 close 시 소스/리스너/좌석 점유를 정리한다. 이를 모든 기기에서 새로 실행한 것으로 확대하지 않는다.
- 다섯 MP3의 SHA-256·크기가 `source/music-manifest.json`(3곡)과 `source/music-extra-manifest.json`(2곡)에 모두 일치한다. 작곡·합성 스크립트 및 `DormiMusic.txt`, `music-extra.txt`, `string-instruments.txt` 고지는 보존돼 있다. 기존 제작 기록은 절차적 작곡/합성·외부 샘플 미사용으로 명시한다. 이번 확인은 파일 일치·고지 검토이며 저작권 독점성·유사성·상업 권리 보증이 아니다.

## 다음 실제 UI 검수안

기기: 320×568 터치, 390×844 터치, 844×390 터치, 1440×900 키보드. 기존 `scripts/final-visual-detail-2026-11-01.mjs`의 이동/최소 위치 준비를 참고하되, 최초 진입은 실제 지도 → 학교 → 음악실 → 실제 행동 버튼으로 한다. 화면 캡처 전 강제 scrollIntoView를 하지 않고 초기 가시성과 사용자의 패널 스크롤을 구분한다.

1. **감상 전곡:** 다섯 곡 각각 선택 → Play → 상태/실제 audio.playing 일치 → 멈추기 → 무음 → 다시 Play → mute/volume/unmute → 닫기·잠금 해제. 첫 화면 제목/나가기와 패널 스크롤로 마지막 곡·재생·음량 접근을 캡처한다. 재입장 시 이전 소스·좌석 점유가 남지 않아야 한다.
2. **실패 회복:** 첫 요청 503/MP3 decode 실패/AudioContext 없음/늦은 decode를 각각 주입. 실패 뒤 volume·mute·다른 곡 선택만으로 소리가 재시작하면 실패. 새 Play로만 재시도하고 표시·실제 곡이 일치해야 한다. 로딩 중 멈추기·다른 곡·닫기/재입장·탭 숨김 뒤 늦게 끝난 요청이 재생하거나 새 창 상태를 덮지 않아야 한다.
3. **퀴즈 완주:** 6문항 모두 오답 설명·다시 생각하기·정답·다음, 6/6 완료와 처음부터, 도중 닫기/재입장. 키보드 Enter로 답을 고른 직후 활성 요소/Tab, Next→새 첫 답→Tab, 마지막 Next→Restart→Enter의 목적지를 기록하고, 글·음표·세 선택지·버튼을 실제 스크롤로 읽을 수 있어야 한다.
4. **음악 휴식 한계:** UI와 AudioContext 이벤트 검증은 실제 스피커 음량·음질·루프 경계·iOS Safari 검수를 대체하지 않는다. 새 콘텐츠나 점수/보상은 이번 검수의 선행 조건이 아니다.

실제 앱 harness: [scripts/music-listening-acceptance-2026-11-06.mjs](../scripts/music-listening-acceptance-2026-11-06.mjs). 문법 검사만 통과했으며 아직 실행하지 않았다. 실제 지도·행동 버튼으로 진입하고 첫 `windowlight.mp3`만 503으로 응답시킨다. 실패 뒤 음량/음소거/선택만으로 요청·소리가 재시작하지 않는지, 명시적 Play 회복, 다섯 곡의 정상 decode/재생/정지, 퀴즈 6문항 완주와 키보드 초점 전환을 검사한다. Web Audio는 실제 브라우저 것을 사용하지만 `--mute-audio`이므로 청취 검증으로 세지 않는다. decode/unlock 실패와 늦은 완료의 세부 분기는 CPU 회귀에 있으며 현재 실제 앱 harness는 503 경로만 주입한다.

기기별 `QA_WIDTH`, `QA_HEIGHT`, `QA_DESKTOP`, `QA_OUT`과 동결된 서버의 `QA_BASE`를 지정하여 승인된 브라우저 슬롯에서 실행한다. 전체 패키지 검사·3D 음악 검수·실제 청취·push/배포는 이 격리 작업에서 수행하지 않았다.
