## 판정과 남는 범위

체육관 7기구와 운동장 5활동은 메뉴명에 맞는 짧은 놀이/휴식 기능을 제공한다. 실제로 발사되지 않던 두 조준 기구를 수정한 뒤, 각각의 대표 입력→판정→결과/재시도까지 확인해 **이 범위는 공개 배포에 합격**으로 판단한다.

‘모든 모드·모든 난이도의 완주’나 시판 전용 스포츠 앱 수준의 깊이로 확대해 해석해서는 안 된다. 러닝머신의 30초 자동 전체 반복, 5회 패스/공 던지기 도전 전체, 모든 클라이밍 경로, 모든 스포츠 난이도는 이번 브라우저 표본의 완료 범위에 포함하지 않았다. 공 굴리기는 점수 없는 산책 장난감이고, 운동 기구는 실제 사용자의 운동량을 측정하지 않는다. 이는 현재 안내와 맞으며 배포 차단 결함으로 보지 않는다.

제품 수정 파일은 별도 담당자의 `dist/gym/archery-rig.js`, `dist/gym/laser-rig.js`다. 이 담당 작업의 추가 파일은 전용 QA 스크립트와 이 보고서뿐이며, 완료 후 브라우저를 모두 닫았다.

공용 4173 서버가 켜진 상태에서:

```sh
QA_CURLING_FULL=1 QA_RENDER_SCALE=0.5 QA_RENDER_EVERY=12 node scripts/remaining-sports-acceptance.mjs
```

`QA_SPORTS=archery,curling,baseball`로 시나리오 선택 가능. 타임아웃은 느린 소프트웨어 렌더러를 고려하며 모델 시계를 바꾸지 않는다.

추가 교차 검증 명령:

```sh
QA_SPORTS=archery QA_ARCHERY_SHOTS=1 QA_ARCHERY_METHOD=pointer QA_RENDER_SCALE=0.5 QA_RENDER_EVERY=1 QA_OUT=qa/remaining-sports-normal-render-2026-11-01 node scripts/remaining-sports-acceptance.mjs
QA_SPORTS=archery,curling,laser,boxing,passing QA_CURLING_FULL=1 QA_RENDER_SCALE=0.5 QA_RENDER_EVERY=12 QA_OUT=qa/remaining-sports-recheck-2026-11-01 node scripts/remaining-sports-acceptance.mjs
QA_SPORTS=archery,laser-aim QA_ARCHERY_SHOTS=1 QA_ARCHERY_METHOD=touch QA_MOBILE=1 QA_WIDTH=390 QA_HEIGHT=844 QA_RENDER_SCALE=0.5 QA_RENDER_EVERY=12 QA_OUT=qa/remaining-sports-phone-2026-11-01 node scripts/remaining-sports-acceptance.mjs
```
