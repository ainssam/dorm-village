## fixture와 검증의 독립성

v5/v6 JSON은 schema7 편집 **전에** 기준 커밋 `fe86624`의 실제 schema6 validator/migrator로 먼저 valid임을 확인한 합성 회귀 데이터다. 현재 초기값이나 새 카탈로그를 이용해 옛 키 집합을 만드는 방식은 사용하지 않았다. 출처와 범위는 `tests/fixtures/harvest-meal-history.md`에 적었다.

v1–v4는 고정 v5 데이터에서 해당 버전 이후 필드를 제거한 파생 형식으로 migration 경로를 확인한다. 해당 시기의 실제 사용자 기록 또는 모든 과거 버전 조합으로 확대하지 않는다. 이전 공개판 loader가 v7을 미래 버전으로 막는 검증은 commercial 담당의 원본 모듈 VM 대조 근거이며, 이30개 안에 포함해 세지 않았다.

제어 테스트는 실제 cafe controller·tea controller·root reducer·revision 증가·validateProgress를 연결한다. 외부 표현/좌석 동선/비동기 로딩/저장 승인만 fixture로 격리한다. 소비 성공을 상태에 직접 주입하지 않고 실제 action을 통해 수량을 확인한다. 테스트의 tick은 제어 경계 검증이며 실제 애니메이션을 완주한 브라우저 증거가 아니다.

사진 보존 검사는 실제 메타데이터 구조와 별도 저장소 문자열 불변을 확인한다. 사진 문자열은 합성 경계 데이터이며 이미지 품질이나 디코딩을 검증한 것으로 설명하지 않는다.
