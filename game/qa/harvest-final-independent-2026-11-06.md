## 제품 방향과 문구

기존에 쌓기만 하던 채소가 한 번 수확→내 몫/친구 몫→카페 휴식으로 이어진다. 새 수집 완주 의무, 출석 보상, 만료, 강제 친구 초대 또는 결제는 추가하지 않았다. 한 재료로 시작할 수 있고 모두 소진해도 무료 음료와 휴식이 남는다. 이는 힐링·휴식·즐거움이라는 모토와 맞는 작은 생활 연결이다.

토마토/호박의 열매, 잎채소의 잎, 실제 그릇의 색·조각을 짧게 관찰한다. 하지 않은 칼질·가열 과정을 배웠다고 하거나 건강 효과를 보장하지 않는다. 이름/단위와 필요량은 카탈로그에 맞고 기존 빵·음료는 각각 개/잔으로 남는다. 이 코드 검토는 실제 사용자 재미나 학습 효과를 측정하지 않았다.

## 근거를 부풀리지 않기 위한 경계

기존 보고서와 fixture 출처도 대조했다. v5/v6 자료는 기준 원본 validator가 승인한 합성 기록이며 실제 사용자 저장이 아니다. v1~v4는 원본에 명시된 호환 구조를 재생한 자료이고 당시 배포 앱의 아카이브가 아니다. 메모리 저장소의 실패/두 writer 테스트와 물리 기기 저장 오류·동시 브라우저 탭 실험을 구분해야 한다.

이 담당은 새 전체 테스트를 중복 실행하지 않았고 전체 통과 개수를 추가 주장하지 않는다. `git diff --check`는 통과했다. 장면 손 접촉·실제 화면 회전·기본 카메라 가림·브라우저의 세 채소/기존 빵·음료 완주는 담당자의 최종 캡처와 결과를 출시 보고서에서 연결해야 한다. cloned-camera 접촉 화면은 기본 게임 카메라의 사용성 증거와 분리한다. 실물 Safari·저사양 기기의 성능, 장기 이용과 지불 의사도 이 검토로 합격 처리하지 않는다.
