# 오늘의 작은 발견 · 원고 검수 · 2026-11-01

## 범위와 편집 방향

`dist/village/data/daily-discoveries.js`에 직접 쓴 한국어 카드 60개를 제공한다. 자연·과학·말과 글·예술·함께 사는 하루·생활의 원리를 각 10개씩 담았다. 각 원고는 2문장의 짧은 읽을거리, 관찰/생각 질문, 실제 마을에서 할 수 있는 구체적인 놀이, 선택적으로 떠올릴 마음 질문으로 구성한다. 최종 읽을거리의 길이는 72~114자다.

실제 개념을 한 가지 알아가는 것을 목표로 했다. 예를 들어 ‘물방울과 수증기의 차이’, ‘추 질량과 진자의 왕복 시간’, ‘화면의 빛과 물감의 혼합 차이’, ‘재료 농도와 젓기의 차이’, ‘훈민정음 창제와 책 간행의 차이’를 설명한다. 동일 문장에 명사만 교체하는 방식으로 양을 늘리지 않았다. 관계와 마음에 관한 글은 일반적인 대화/관찰 제안이며 검증된 심리 효과를 주장하지 않는다.

이 파일은 **정적으로 큐레이션한 60개 원고 묶음**이다. 한국 날짜에 따른 선택과 지난 카드 열람은 별도의 게시판 코드가 담당한다. 매일 취재한 새 정보, 실시간 뉴스, 외부 자료 자동 갱신이라고 표현하지 않는다. 이 콘텐츠는 모듈 자체에서 날짜·계정·저장·알림·개인정보·외부 통신을 다루지 않는다.

## 사실과 표현 검토

| 영역 | 확인한 핵심과 한계 |
| --- | --- |
| 자연 | 잎의 기존 노랑/주황 색소와 일부 식물의 붉은 색소 생성, 씨앗의 이동, 물 표면 반사, 곤충/바람에 의한 수분, 수증기와 구름의 차이, 자전축 기울기와 양 반구의 계절, 물순환, 나무 그늘을 구분했다. 모든 꽃·나무에 같은 특성을 일반화하지 않는다. |
| 진자·균형 | 작은 진폭·저항을 무시하는 이상화 조건을 질량 카드에 명시했다. 길이 비교는 다른 조건을 고정한다. 돌림힘은 무게와 거리의 관계로 설명하고, 건축 놀이는 층별 받침도 살펴야 한다고 적었다. |
| 빛·색·예술 | 빨강/초록/파랑 빛의 가산 혼합과 물감 혼합을 구분했다. 배경에 따른 색의 인상, 선·여백·리듬의 느낌은 가능성 표현을 사용해 취향의 정답을 요구하지 않는다. |
| 말·역사 | 자음/모음/받침의 구성과 의성어/의태어 예시를 구분했다. 훈민정음은 1443년 창제와 1446년 책 간행을 나누어 기존 한글 이야기의 표현과 맞췄다. 영어 복수형에는 예외가 있고 번역이 낱말의 일대일 치환은 아님을 적었다. |
| 요리 | 같은 컵이라는 부피 단위, 재료 비율, 농도와 섞임을 구별했다. 게임의 가열은 단순 모형이며 실제 온도·안전·조리법을 제공하지 않는다고 밝혔다. 재료 담는 순서는 보이지만 결과 차이를 계산하지 않는 현 구현과 맞췄다. |
| 지도·하늘·확률 | 세계지도의 왜곡과 나라 경계 미표시를 고려해 적도·대륙 단위로 안내했다. 시간대는 경도만으로 확정하지 않는다. 별의 겉보기 밝기를 거리와 동일시하지 않는다. 반반 확률이 매 실행의 반반 결과나 갈톤보드 각 도착 칸의 같은 수를 뜻하지 않음을 다뤘다. |
| 함께 사는 하루 | 도움 요청, 사진 촬영/공개의 구분, 다른 관점, 열린 질문 등을 선택의 언어로 썼다. 실제 사람에게 연락하거나 사진을 공유하라는 지시가 없다. 사진관의 친구는 게임 속 캐릭터라고 구분한다. |

일반적으로 확립된 기초 개념을 편집 검토했고, 실제 기능 및 모형의 조건은 아래 저장소 소스와 대조했다. 별도 외부 실시간 검색이나 전문 분야 감수를 수행했다고 주장하지 않는다. 기존 국어실의 사전 뜻풀이를 복사하지 않았고, 기존 동화 본문을 새 읽을거리로 재수록하지 않았다. 책 제목은 실제 게임 내 책을 찾기 위한 안내다.

## 실제 활동과의 대응

`dist/world/rooms.js`를 실행해 카드 60개 모두의 `play.roomId`, 지도 목적지와 실제 스폰 존재를 확인했다. 고유 목적지는 16곳이다.

| 목적지 | 참조한 현재 기능/소스 |
| --- | --- |
| `art` | 그리기와 「같은 꽃, 다른 배경」. `dist/school/tools.js`, `dist/school/learning-model.js` |
| `science` | 진자 실험실, 빛의 색 실험, 「작은 추, 긴 팔」. `dist/world/school.js`, `dist/school/tools.js`, `dist/school/learning-model.js` |
| `korean` | 자모 조합, 순우리말 사전과 예문, 이야기 잇기, 훈민정음 액자. `dist/school/korean-room.js`, `dist/korean/view.js`, `dist/school/subject-exploration-model.js` |
| `english` | 그림 사전/책, 문장 카드, 카페 역할놀이. `dist/school/english-room.js`, `dist/school/subject-tools.js` |
| `library` | 실제 세 동화 제목, 책장·의자·세 주민·사서 의뢰. `dist/state/library.js`, `dist/world/library-layout.js`, `dist/library/quest-controller.js` |

| `homePlayroom` | 탑, 「골짜기 건너기」, 받침 배치와 기울임 시험. `dist/home/balance-lab.js`, `dist/home/balance-controller.js` |

꽃의 수분·물순환·나무 수종·그늘·물의 반사에 관한 글은 현상을 설명한 뒤 마을 풍경 관찰이나 그리기로 연결한다. 마을 렌더러가 실제 생태·광학·일주 운동을 정확하게 재현한다는 주장을 하지 않는다. 사서 의뢰 등 기존 놀이에 결과 표시가 있더라도 이 카드들은 도장 획득·완료 횟수·출석·연속 기록을 요구하지 않는다.

## 실행한 확인

- Node ES 모듈 import 및 `node --check dist/village/data/daily-discoveries.js` 통과.
- `npm run check` 통과(`All authored JavaScript syntax checks passed`). 전체 게임 회귀 테스트는 통합 작업의 검증 기록에서 확인한다.
- 정확히 60개, ID 60개 고유, 제목 60개 고유, 6주제 각각 10개 확인.
- 모든 필수 값의 문자열 타입과 `play`의 세 필드 확인.
- 각 읽을거리의 문장 수가 2~3문장 범위임을 확인(모두 2문장).
- 현재 `ROOMS` 모듈과 `mapDestination()`을 import하여 60/60 목적지 및 스폰의 실재 확인.
- 금전/보상/연속 출석·성적 압박, 진단·치료 효능, 실제 배송·공유·개인 답변 저장을 약속하는 문구가 없는지 편집 검토.

원고 파일은 DOM이나 게임 상태를 변경하지 않는다. 통합 화면의 한국 날짜 전환·지난 카드 선택·닫기·이동과 모바일 표시 검증은 별도 게시판 구현/브라우저 QA의 범위이며 이 문서에서 수행 완료로 주장하지 않는다. 모든 연결 활동을 이번 원고 작업에서 새로 끝까지 플레이한 것은 아니다. 장기 사용자의 난이도·반복 피로, 실물 모바일 가독성, 실제 이용자 반응과 학습 효과는 검증하지 않았다. 60개 카드가 날짜에 따라 순환하므로 61일째 이후에는 이미 본 원고가 다시 나올 수 있다.
