# 도름마을 출시 검수 기록

검수일: 2026-10-24 (한국). 출시 대상: 아인2의 `dorm-village`. 기준 소스: `afd7270eb5912800a566a2976519f7b1e68b5f03`에서 시작한 `codex/dorm-village-release`.

## 판정

로컬 출시 관문 통과. 모든 장소와 개별 상호작용 진입을 순회했고, 주요 사용 흐름·저장 보호·오류 복구를 확인했다. Vercel의 빌드에서도 문법 검사와 189개 테스트를 다시 실행하도록 설정했다.

## 변경 내용

- `doreumi-desktop-pet` 마스터의 원래 관절·스킨·표정을 유지한 도름이. 39,331개 정점, 64,024개 삼각형, 약 1.9 MB GLB. 원본/파생 해시와 출처는 `dist/characters/doreumi/source.json`에 기록했다.
- 기존 활동의 CPU 참조 좌표에서 새 관절로 좌석·악기·운동·음식 동작 연결. 원본을 보존하고 팔의 늘어짐과 갈라짐을 방지했다.
- 마을 길과 잔디, 천문대, 카트·코스터·범퍼카의 식재·바닥 마감. 조명과 노출 조정.
- 비행기 창·날개·지지대·항법등·도장과 외피 보강. 탑승 패널의 상단/하단 지정 충돌 수정.
- 최초 안내, 장소/활동 검색, 저장 범위 안내, 출처 페이지, 웹앱 manifest/아이콘, 모바일 제목/버튼 배치.
- 인형뽑기·음식 카트·체육관 도구가 참조하는 `velocity`의 잘못된 선언 범위 수정.

## 검증 범위와 한계

Chromium과 소프트웨어 WebGL에서 확인했다. 반복 기능 검사는 CSS 크기를 유지한 채 렌더 해상도를 낮췄고, 데스크톱 1280×900과 모바일 390×844의 원래 해상도 화면도 별도로 검토했다. 실제 iOS Safari/Android GPU의 프레임 속도·배터리·장시간 메모리 사용량을 측정한 결과는 아니다. 모든 상호작용 진입 검사와 모든 게임의 모든 선택지/승패 조합 완주 검사는 구별한다.

기록은 브라우저에 저장된다. 다른 주소·기기·브라우저로 자동 이전되지 않으며 브라우저 데이터를 삭제하면 사라진다. 최초 방문과 출처 페이지에서 안내한다.

`qa/`의 이미지와 원시 JSON은 로컬 검수 산출물이다. 재현 방법은 `game/README.md`를 참고한다. 테스트 이동 브리지는 Playwright 응답 가로채기에만 주입되고 배포 소스에는 포함되지 않는다.
