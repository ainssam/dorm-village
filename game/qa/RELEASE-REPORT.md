# 도름마을 재검수 · 2026.10.25.1

사용자 피드백에 따라 보행·길 표시·글꼴·실제 놀이 흐름을 다시 검수했다. 이전의 180개 진입 검사는 기능이 열리는지 확인한 기록이며, 보행의 자연스러움이나 착석 완료 상태의 품질을 입증하지 못했다. 아래 이전 출시 기록과 이번 검증을 구분한다.

## 이번에 재현하고 고친 문제

- 걷기 강도 `.25`가 기존 짧은 발 변위에 다시 적용되어 새 도름이의 발 이동 폭이 약 3.7cm에 그쳤다. 새 관절에 맞는 팔 교차 운동·고관절·무릎·발목 보행으로 교체했다. 실제 발 이동 폭은 약 19cm, 손은 약 28cm이며, 멈추면 원래 관절로 부드럽게 돌아간다. 바닥 접촉은 실제 피부 메시에서 측정한다. 24개 보행 표본의 최저점 오차는 약 0.3mm 이내였다.
- 좌석 이동 후 `SkinnedMesh.bindMatrixInverse`가 갱신되지 않아 높이 오차가 누적됐다. 그네에서는 도름이가 좌석 아래로 내려갔다. 부모 변환 → 스킨 바인딩 → 관절 행렬 순서로 갱신하도록 수정하고, 움직이고 기울어진 좌석에서도 실제 메시의 로컬 높이가 유지되는 회귀 검사를 추가했다.
- 캐시된 포즈 프레임에서 소품의 손 좌표가 예전 캐릭터 좌표로 되돌아갔다. 새 도름이의 손 좌표를 그대로 유지하도록 수정했다.
- 마을과 코스터 바닥의 반복 점선 테두리를 제거했다.
- UI는 자체 호스팅 Pretendard 가변 글꼴로 통일하고, 제목·본문·보조 설명·버튼 크기와 굵기를 구분했다. 3D 세계의 손글씨 간판과 기존 라이선스는 보존했다.
- 놀이 검색이 장소 소개에만 의존해 양궁 등의 실제 기능을 찾지 못했다. 각 장소의 실제 활동 이름과 러닝머신/트레드밀, 복싱/권투 등의 표현을 함께 찾고 검색된 놀이 이름을 결과에 표시한다.
- 이야기 순서·영어 낱말 놀이 결과에서 바로 다시 할 수 있게 했다.
- 휴대폰의 로봇 공방에서 명령 편집 중 실행 버튼이 멀어졌다. 실행·멈춤 도구를 하단에 유지하고, 실행하면 로봇이 보이는 위치로 이동한다.

## 디자인 방향과 검수 방식

장면과 가까운 행동을 우선한다. 본문은 15–16px의 명확한 한글 서체, 보조 안내는 12–14px, 터치 영역은 44px 이상을 기본으로 한다. 크림색 배경과 짙은 녹색 글씨를 유지하며, 반복 테두리와 불필요한 화면 왕복을 줄인다. 기존 모바일 제품의 한 화면 한 작업 원칙과 저장·되돌리기 패턴을 참고했다. 디자인 스킬의 외부 참고 파일은 접근되지 않아 기존 제품을 직접 렌더링하며 판단했다.

이번 브라우저 검사는 기본적으로 **일반 동작 설정**을 사용한다. `QA_REDUCED=1`일 때만 움직임 줄이기를 켠다. 걷기는 실제 키 입력과 터치 스틱 입력 후 관절 변화를 확인한다. 착석은 진입 순간 대신 `active`까지 기다리고, 놀이 완료·다시 하기·저장 후 열기를 별도로 확인한다.

- 브라우저 캡처와 상세 JSON은 저장소에서 제외된 로컬 검수 자료이며, 재현 스크립트는 `scripts/`에 포함했다.

## 검증 범위와 한계

Chromium과 소프트웨어 WebGL에서 확인했다. 반복 기능 검사는 CSS 크기를 유지한 채 렌더 해상도를 낮췄고, 데스크톱 1280×900과 모바일 390×844의 원래 해상도 화면도 별도로 검토했다. 실제 iOS Safari/Android GPU의 프레임 속도·배터리·장시간 메모리 사용량을 측정한 결과는 아니다. 모든 상호작용 진입 검사와 모든 게임의 모든 선택지/승패 조합 완주 검사는 구별한다.

기록은 브라우저에 저장된다. 다른 주소·기기·브라우저로 자동 이전되지 않으며 브라우저 데이터를 삭제하면 사라진다. 최초 방문과 출처 페이지에서 안내한다.

`qa/`의 이미지와 원시 JSON은 로컬 검수 산출물이다. 재현 방법은 `game/README.md`를 참고한다. 테스트 이동 브리지는 Playwright 응답 가로채기에만 주입되고 배포 소스에는 포함되지 않는다.
