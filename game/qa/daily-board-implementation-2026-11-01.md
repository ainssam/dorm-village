# 오늘의 작은 발견 구현 기록 · 2026-11-01

기존 공개 앱 목록을 날짜별로 정해지는 로컬 큐레이션 카드로 교체했다. 한국 시간의 날짜를 기준으로 같은 날짜에는 같은 카드를 보여 주며, 오늘을 포함한 최근 7일을 이전·다음·오늘 버튼으로 둘러본다. 표시 날짜는 게시나 실시간 갱신 시각이 아니며, 화면에도 검토한 읽을거리를 날짜에 맞춰 고른다고 밝힌다. 답변 입력이나 별도 저장은 없다. 장소 버튼은 공통 장소 이동 API를 이용한다.

날짜 선택은 윤일·연말·한국 시간 자정 및 카드 순환을 단위 검사한다. 리더 검사에서는 7일 범위, 날짜 변경, 이동 요청과 닫은 뒤 오래된 콜백 무효화를 확인한다. 브라우저 검사는 휴대폰·태블릿·데스크톱 크기에서 실제 클릭/터치로 날짜 이동, 장소 요청, 다시 열기와 가로 넘침을 점검한다. 브라우저 검사는 간단한 워크숍 호스트를 사용하므로 3D 장면에서의 진입과 실제 이동까지 보증하지 않는다.

## 실행 결과

- `node --test tests/daily-discovery-model.test.mjs tests/daily-discovery-reader.test.mjs tests/ui-lifecycle.test.mjs`: 통과 (6개 테스트 파일/검사 단위, 실패 0). 실제 카드 모듈을 import하고, 리더에는 날짜별 탐색을 분명히 확인할 수 있는 테스트 카드를 주입했다. 공통 모달 픽스처는 반복 열기·닫기와 정리를 확인한다.
- `node scripts/daily-discovery-browser.mjs`: Chromium에서 375×812, 812×375, 768×1024, 1024×768, 1280×800 모두 통과. 실제 카드 모듈을 사용하고 모바일/태블릿은 터치, 데스크톱은 클릭으로 날짜 경계·장소 요청·다시 열기·닫기와 문서 가로 넘침을 검사했다.
- 위 브라우저 검사는 3D 장면 대신 간단한 워크숍 호스트로 실행했다. 실제 모달의 장소 이동 및 3D 장면 통합 확인은 별도의 전체 장면 검수 범위다. 실물 기기와 iOS Safari 검사는 포함하지 않는다.
