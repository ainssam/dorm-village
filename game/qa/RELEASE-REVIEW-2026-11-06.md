## 공개 주소 검증과 한계

[공개 검증 JSON](deployment-2026-11-06.json)에 실제 Vercel 상태와 공개 응답을 남겼다. 메인 `application-version`은 `2026.11.06.1`, canonical/OG는 공개 주소다. `manifest.webmanifest`와 `brand/source.json`은 검수 소스와 JSON 내용이 일치한다. 홍보 이미지는 1200×630, 파비콘은 64×64 응답으로 확인됐다. 추출 도구가 HTTP 상태 숫자를 제공하지 않으므로 임의로 HTTP 200이라고 기록하지 않는다.

로컬 실행 환경은 공개 주소로의 직접 연결이 차단되어 있고, 별도 외부 브라우저는 WebGL을 제공하지 않아 기존 공개판에서도 3D를 시작하지 못했다. 이 환경에서 새 공개판의 3D 조작까지 완료했다고 표현하지 않는다. **전체 게임의 동작 검수는 배포에 고정한 동일 소스를 로컬 Chromium/소프트웨어 WebGL로 실행한 결과**이고, 공개 주소의 확인은 READY·버전·정적 자산 범위다. HTML 추출에 포함된 숨김 오류 문구 자체를 공개 앱 장애로 단정하지 않는다.

실물 iPhone/iPad/Android·Safari의 성능, 스크린리더 청취, 장시간 발열·배터리, 실제 이용자의 재방문·지불 의사는 별도 검증 대상이다. 현재 무료 공개 개선을 유료 판매 권리 확보로 확대하지 않는다. 자산과 외부 날씨 서비스 조건은 [상업 준비 검토](commercial-readiness-2026-11-06.md)에 기록했다. 도름스 앱 게시판 등록은 이 배포와 별개이며 완료했다고 기록하지 않는다.
