# 에셋 제작 원본

이 폴더에는 게임 에셋을 계속 다듬을 때 참고할 수 있는 선택된 모델·이미지·지도·음악 생성 코드와 공개 라이선스가 있는 입력 파일이 들어 있습니다. 일반적인 브라우저 실행에는 필요하지 않으며, 실제 게임은 `../dist/`의 편집 가능한 모듈과 자산을 사용합니다.

Python 기반 캐릭터·소품 빌더는 Blender의 Python API(`bpy`)가 필요할 수 있습니다. 일부 Node 기반 도구는 해당 하위 폴더의 별도 패키지 설치가 필요합니다. `npm ci`는 게임 실행과 테스트용 의존성만 설치합니다. 생성 스크립트를 쓰기 전에 출력 경로와 필요한 제작 도구를 확인해 주세요.

각 에셋의 저작권·폰트·데이터 고지는 해당 `LICENSE`, `NOTICE` 파일과 `../dist/licenses/`에서 확인할 수 있습니다. 고지문은 에셋을 수정해도 함께 보존해 주세요.
